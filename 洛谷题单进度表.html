B2002 Hello,World!
输出一行 Hello,World!。 坑在这里：逗号后面没有空格。写成 Hello, World! 会 WA（答案错误）。这是全站最经典的一个坑，第一次踩到能让你记住"输出格式必须逐字符对齐"。
P1001 A+B Problem
输入两个整数，输出它们的和。全站第一题，所有人的起点。
坑 1：scanf("%d%d", &a, &b) —— 两个 & 都要有，漏了会直接崩溃或算出乱数。
坑 2：用 %d 不是 %f，int 和 double 不能混。 输入：1 2　　输出：3
P5703 【深基2.例5】苹果采购
n 个同学，每人 x 个苹果，一共要买多少。
这是第一道"要用变量算"的题：不再是 a+b 这种现成式子，你要自己写出 n*x。
坑：数据范围。看清楚题目给的 n、x 上限，想想 int 够不够（够，但要养成看范围的习惯——这是以后被 long long 坑的开始）。

三个必须知道的坑
① 翁恺用的是 Dev-C++（P6 专门讲这个），你装的是 w64devkit + VS Code，不用换。Dev-C++ 早就淘汰了，跟着他敲代码就行，环境差异不影响理解。
② 每集都要跟着敲。他最大的价值是边讲边写，你光看等于看剧。看一集 = 敲一遍 = 改几个参数看结果，三步都要有。
③ 1.5 倍速，第一遍别上 2 倍。他语速本来就慢，1.5 刚好；2 倍会漏掉他讲"为什么这么写"的那几句，而那才是重点。
最重要的一句：翁恺的课解决的是「不知道 C 有什么」，不解决「写不出程序」。后者只能靠项目。
如果你看完指针那三集，觉得"好像懂了"但一动手还是空白——这是正常的，因为看懂和写出来之间隔着几十次动手。指针看第一遍不懂也完全没关系，等 12 月写通讯录时再看第二遍就通了。
如果现在就想看点什么：只推荐 P81–P83 指针三集（共 33 分钟）——取地址运算 / 指针是什么 / 指针怎么用。这是 C 语言最反直觉的部分，早看早解脱，而且不需要任何前置知识。其余的都等到对应月份再看。

怎么用这份表

  • 每天固定 3 题，按表里的顺序做，不要跳着做。题号顺序就是难度顺序，洛谷官方排的。
  • 卡住超过 20 分钟就看题解，不要硬耗。看题解的正确方式是：看懂思路 → 关掉题解自己重写一遍 → 能独立写出来才算过。
  • 标「可跳」的题真的可以跳，别强迫症。B2025 和 P1000 是字符画，P2433 是阅读理解，跳过它们不影响任何后续内容。
  • 提交时语言选「C」（不是 C++）。洛谷对 C 支持很好，但注意 C 没有 bool、没有 string，遇到这些要自己换写法。
和蓝桥杯的关系：入门 1–2 只是热身，真正对应蓝桥杯省赛难度的是【入门3】之后的【入门4 数组】【入门5 字符串】【算法1-1 模拟】【算法1-2 排序】。你现在这 45 题的目标不是"会做难题"，是把「读输入 → 处理 → 按格式输出」变成肌肉记忆——这是所有算法题的外壳，壳不熟，里面的算法再懂也拿不到分。
一个提醒：不要为了赶进度复制题解。刷题的唯一价值是你想不出来、然后想出来了的那个瞬间。复制粘贴 100 题，不如自己啃下来 10 题。
