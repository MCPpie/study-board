第 1 段 · 为什么要多一种管子 P1–P2 · 8 分钟

01P1–P2　引言：FET 是什么8 分钟
这一页只讲一件事：三极管不够用的地方，场效应管补上
  • 定义：利用输入回路的电场效应控制输出回路电流的半导体器件 → 属于电压控制型器件（三极管是电流控制型）
  • 单极性：只有一种载流子参与导电（三极管是两种，叫双极性）
  • 为什么需要它：有些信号源极其微弱、内阻极大，只能提供微安级甚至更小的电流。这时放大电路必须输入电阻极高——只有 FET 做得到
  • 分类：结型 JFET（大纲不要求）+ 绝缘栅型 IGFET / MOSFET（增强型、耗尽型，各有 N/P 沟道）
  • 三个电极：源极 s、栅极 g、漏极 d —— 对应三极管的 e、b、c
可跳：P2 里结型 JFET 的整条分支（课件自己标了「大纲不要求」）；P1 的目录页扫一眼

第 2 段 · 增强型 MOSFET 怎么工作 P3–P5 · 15 分钟

02P3　结构和符号6 分钟
这一页只讲一件事：栅极是「隔着绝缘层」控制的
  • 结构：P 型衬底上做两个 N+ 区（源、漏），栅极下面隔一层 SiO₂ 绝缘层
  • 为什么输入电阻能到 10⁹ Ω 以上：栅极和沟道之间是绝缘的，根本不流过电流
  • 符号怎么认：
    · 衬底箭头向里 = N 沟道（向里 = 指向 P 型衬底）
    · 漏、衬底、源断开 = 增强型（零栅压时沟道不通）
    · 漏、衬底、源连着 = 耗尽型（零栅压时沟道已通）
  • 三个工作区与三极管一一对应：夹断区↔截止区、恒流区↔放大区、可变电阻区↔饱和区
易错：「恒流区」对应的是三极管的「放大区」，「可变电阻区」才对应「饱和区」——名字很像但千万别按字面配
03P4–P5　工作原理：两个电压各管什么9 分钟
这一页只讲一件事：uGS 开沟道，uDS 只负责「夹断」
  • (1) uGS 控制沟道有无：
    · uGS > 0 但较小 → 不足以形成沟道，iD = 0
    · uGS > UGS(th)（开启电压）→ 形成 N 型导电沟道，才有电流
  • (2) uDS 的作用分两段：
    · uDS 较小时：iD 随 uDS 增大而增大（可变电阻区）
    · 漏极处出现预夹断后：uDS 增加的部分几乎全落在夹断区上，iD 只受 uGS 控制（恒流区）
  • 预夹断条件：uGD = uGS − uDS = UGS(th)（N 沟道增强型）
  • 一句话记住：uGS 决定「有没有水」，uDS 决定「水流是否已经稳定」
可跳：P5 右侧那些不同 uGS 下的沟道剖面图，看懂第一张和「夹断」那张就够

第 3 段 · 两条特性曲线（全章命门） P6–P7 · 12 分钟

04P6　输出特性曲线 iD = f(uDS)6 分钟
这一页只讲一件事：一族曲线，四个区
  • 横轴 uDS、纵轴 iD，每条曲线对应一个固定的 uGS
  • 四个区（要能一眼指出来）：
    · 可变电阻区：uDS 小，曲线陡，管子像一个受 uGS 控制的可变电阻
    · 恒流区：曲线几乎水平，iD 只看 uGS → 放大就工作在这里
    · 夹断区：uGS < UGS(th)，iD ≈ 0
    · 击穿区：uDS 太大，iD 暴涨，会烧管子
  • 预夹断轨迹：把各条曲线上「uGD = UGS(th)」的点连起来，就是可变电阻区和恒流区的分界线
05P7　转移特性 iD = f(uGS)6 分钟
这一页只讲一件事：一条抛物线，一个公式
  • 是什么：固定 uDS（取恒流区内，如 10V），画 iD 随 uGS 的变化
  • 公式（增强型，恒流区）：iD = IDO·(uGS/UGS(th) − 1)²
  • IDO 的定义：uGS = 2UGS(th) 时对应的 iD——不是 uGS=0 时的电流（那时是 0）
  • 曲线形状：从 uGS = UGS(th) 处开始起翘，是一条开口向上的抛物线
  • 这个公式的用途：静态分析时和偏置方程联立，解出 IDQ 和 UGSQ
易错：IDO ≠ IDSS。增强型用 IDO（uGS=2UGS(th) 时），耗尽型用 IDSS（uGS=0 时）——两个符号千万别混

第 4 段 · 耗尽型（了解即可） P8–P11 · 8 分钟

06P8–P11　N 沟道耗尽型 MOSFET8 分钟
这一页只讲一件事：出厂自带沟道，所以 uGS 可以是负的
  • 结构差别：SiO₂ 绝缘层里掺了金属正离子，uGS = 0 时就已经形成反型层（沟道）
  • uGS 可正可负：负到 UGS(off)（夹断电压）时沟道才消失
  • 公式：iD = IDSS·(1 − uGS/UGS(off))²，其中 IDSS 是 uGS=0 时的 iD
  • 曲线：转移特性在 uGS 正负两侧都有，横跨纵轴（增强型只在正侧）
可跳：P9–P11 是同一组曲线的重复放大版，看 P9 一眼就够，P10–P11 直接翻过去。课件在这里花 4 页只是把图放大了

第 5 段 · 偏置原则（选择题爱考） P12 · 5 分钟

07P12　六种管子的 uGS 极性5 分钟
这一页只讲一件事：偏置就是「把 uGS 放到能导通又不夹断的区间」
  • N 沟道增强型：uGS > 0 工作，uGS < 0 夹断
  • P 沟道增强型：uGS < 0 工作，uGS > 0 夹断（全部反过来）
  • N 沟道耗尽型：uGS < 0 工作，uGS > 0 也可以（范围宽）
  • P 沟道耗尽型：uGS > 0 工作，uGS < 0 也可以
  • N 沟道结型：uGS < 0 工作，uGS > 0 禁止（会烧栅结）
  • 结论一句话：分压式偏置既能给正偏压也能给负偏压，适合任何类型的场效应管——这就是它成为标准电路的原因
可跳：自给偏压（UGS<0）课件明确写了「不在课上讲解」，只需要知道有这个名字

第 6 段 · 共源放大：静态分析 P13–P15 · 12 分钟

08P13　分压偏置电路长什么样4 分钟
这一页只讲一件事：栅极不取电流，所以栅压纯靠电阻分压
  • 电路元件：Rg1、Rg2（栅极分压）、Rd（漏极）、R（源极）、C1/C2（耦合）、Cs（源极旁路）
  • 关键前提：没有栅流（iG ≈ 0），所以 Rg1、Rg2 就是纯粹的分压器，栅极电位只由它们决定
  • UG = VDD·Rg2/(Rg1+Rg2)
09P14–P15　静态 Q 点怎么算8 分钟
这一页只讲一件事：三个方程联立，解一个一元二次方程
  • 第一步 · 栅源电压：UGSQ = UG − US = UG − IDQ·R
  • 第二步 · 代入转移特性（耗尽型）：IDQ = IDSS(1 − UGSQ/UGS(off))²
    （增强型）：IDQ = IDO(UGSQ/UGS(th) − 1)²
  • 第三步 · 漏源电压：UDSQ = VDD − IDQ(Rd + R)
  • ※ 课件特别提醒：解一元二次方程会得到两组解，必须挑一组合理的——
    判据：uGS 要在导通范围（增强型 UGS>UGS(th)、耗尽型 UGS>UGS(off)），且 UDS > UGS − UGS(th)（保证在恒流区）
  • 验算：算出 UDSQ 后，检查它是否落在恒流区；若 UDSQ 很小说明管子进了可变电阻区，Q 点设错了
易错：R 上有直流压降（US = IDQR ≠ 0），这是和三极管固定偏置最大的不同，别把源极当接地

第 7 段 · 共源放大：动态分析 P16–P19 · 15 分钟

10P16　微变等效模型5 分钟
这一页只讲一件事：栅极开路 + 一个压控电流源
  • 输入回路：g–s 之间输入电阻极大 → 视为开路
  • 输出回路：d–s 之间是一个压控电流源 gmUgs（方向从 d 到 s）
  • 并联的 rds 一般远大于负载 → 可视为开路，得到简化模型
  • 和三极管模型对照：三极管是 ib 控制 βib（电流控电流），FET 是 ugs 控制 gmugs（电压控电流）——其余结构完全一样
11P17　电压放大倍数 Au5 分钟
这一页只讲一件事：Au = −gmRL′
  • Au = −gm·RL′，其中 RL′ = Rd ∥ RL
  • 负号 = 反相：ugs 升高 → iD 增大 → Rd 上压降增大 → uo 下降
  • gm 怎么来：对转移特性求导。gm = 2·√(IDO·IDQ) / UGS(th)（增强型）
    gm = 2·√(IDSS·IDQ) / |UGS(off)|（耗尽型）
  • 量纲：gm 单位是 mS（毫西门子），1 mS = 10⁻³ S
对比记忆：三极管 Au = −βRL′/rbe，FET 是 −gmRL′——少了一个分母，因为栅极不取电流、没有 rbe 这一项
12P18　输入电阻 Ri3 分钟
这一页只讲一件事：Ri 被偏置电阻拉低了
  • Ri = Rg1 ∥ Rg2（栅极本身是开路，所以只剩偏置电阻）
  • 课件的重要提醒：FET 本身输入电阻极高，但并联上偏置电阻后，整个电路的 Ri 并不一定高
  • 怎么提高：P18 下面那个电路——在栅极串一个大电阻 Rg3（几 MΩ），此时 Ri ≈ Rg3 + (Rg1∥Rg2)，一下就上去了
13P19　输出电阻 Ro2 分钟
这一页只讲一件事：Ro ≈ Rd
  • 方法：令 ui = 0、负载开路，输出端加测试电源 uo 求 io
  • ugs = 0 → 受控源 gmugs = 0 → 相当于开路，所以 Ro ≈ Rd

第 8 段 · 共漏 / 共栅 + 三种器件对比 P20–P22 · 8 分钟

14P20–P21　共漏、共栅（只要求了解）5 分钟
这一页只讲一件事：共漏 = 跟随器，共栅 = 输入电阻小
  • 共漏（源极输出器）：Au = gmRL′/(1+gmRL′) → 小于 1、接近 1、同相；Ri 大、Ro ≈ 1/gm 小 → 做缓冲级
  • 共栅：Au = gmRL′ 同相，Ri 小、Ro ≈ Rd 大 → 高频场合
  • 和三极管一一对应：共源↔共射、共漏↔共集、共栅↔共基——性能和用途完全照搬
可跳：P20–P21 只要求「了解结构和性能指标特点」，公式不用背，知道共漏≈跟随器就够
15P22　BJT 与 FET 放大电路对比3 分钟
这一页只讲一件事：控什么、看什么、谁更省事
  • 控制量：BJT 看 iB，FET 看 uGS
  • 输入电阻：BJT 是 kΩ 级（rbe），FET 是 MΩ–GΩ 级
  • 噪声与温度稳定性：FET 更好，适合做前级
  • 跨导：BJT 用 β，FET 用 gm；两者的 Au 都带负号（共源/共射）
