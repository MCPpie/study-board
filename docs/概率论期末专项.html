第 3 章 · 多维随机变量

这一章的难点不是概念，是二重积分的计算量。很多人思路对但算错。

基本工具

联合分布函数
F(x,y) = P(X≤x, Y≤y)
性质：关于 x、y 均单调不减；F(−∞,y)=F(x,−∞)=0；F(+∞,+∞)=1
联合概率密度
F(x,y) = ∫−∞x∫−∞y f(u,v)dudv　，　∬f(x,y)dxdy = 1
边缘密度（最重要）
fX(x) = ∫−∞+∞ f(x,y)dy　，　fY(y) = ∫−∞+∞ f(x,y)dx
积分限是这章的命门：必须按区域画出积分范围，不能一律 −∞ 到 +∞
独立性
f(x,y) = fX(x)·fY(y)
等价于「联合密度能分解成只含 x 的函数乘只含 y 的函数，且区域是矩形」

两个高频题型

① 求边缘密度
三步：画出非零区域 → 固定 x 找 y 的范围 → 积分。
例：f(x,y)=c 在三角形 0<y<x<1 上。求 fX(x) 时 y 从 0 到 x；求 fY(y) 时 x 从 y 到 1。两个方向的范围不一样，这就是最容易错的地方。
② 求 Z = X+Y 的分布（卷积）
fZ(z) = ∫−∞+∞ f(x, z−x)dx
关键还是确定积分限：把 z 当常数，找出使 f(x,z−x)≠0 的 x 范围。通常要对 z 分段讨论。

协方差与相关系数

协方差
Cov(X,Y) = E(XY) − E(X)E(Y)
相关系数
ρXY = Cov(X,Y) / (σXσY)　，　|ρ| ≤ 1
重要关系
D(X±Y) = DX + DY ± 2Cov(X,Y)
独立时 Cov=0，退化成 D(X±Y) = DX + DY
必考概念题：不相关 ≠ 独立
不相关只说明没有线性关系，还可能有非线性关系。但二维正态分布是例外——对正态分布，不相关等价于独立。这个例外一定要记住。

第 6 章 · 数理统计

这一章概念多、公式杂，但题型高度固定。背下来就能拿分。

三大抽样分布

分布构造用途
χ²(n)n 个标准正态的平方和方差的区间估计与检验
t(n)Z / √(χ²(n)/n)均值检验（方差未知）
F(m,n)(χ²(m)/m) / (χ²(n)/n)两个方差之比的检验
三个常用结论（正态总体 X~N(μ,σ²)）
(n−1)S²/σ² ~ χ²(n−1)　　√n(X̄−μ)/S ~ t(n−1)
这两个是区间估计和假设检验的出发点，必须记牢

参数估计两法

① 矩估计（简单，先做这个）
用样本矩代替总体矩：令 E(X) = X̄（或 E(X²) = 样本二阶矩），解出参数。
一个参数用一个方程，两个参数用两个方程。
② 极大似然估计（必考）
四步：写似然函数 L(θ) = ∏f(xi;θ) → 取对数 lnL → 对 θ 求导令其为 0 → 解出 θ̂
注意：取对数是关键一步，直接对乘积求导几乎算不出来。
似然函数的坑：如果 f(x;θ) 里 θ 出现在积分限或指示函数上（比如均匀分布 U(0,θ)），求导法失效，要直接看 L 的单调性取端点。

评价标准

  • 无偏性：E(θ̂) = θ
  • 有效性：两个无偏估计里，方差小的更有效
  • 一致性：n→∞ 时 θ̂ 依概率收敛到 θ

区间估计（背公式即可）

估计对象条件置信区间
均值 μσ² 已知X̄ ± zα/2·σ/√n
均值 μσ² 未知X̄ ± tα/2(n−1)·S/√n
方差 σ²μ 未知[(n−1)S²/χ²α/2, (n−1)S²/χ²1−α/2]

假设检验（四步走）

① 提出原假设 H₀ 与备择假设 H₁ → ② 选统计量（U / t / χ²）→ ③ 定拒绝域（查分位数）→ ④ 比较并下结论
两类错误（可能考简答）
· 第一类错误（弃真）：H₀ 为真却拒绝了，概率 = α
· 第二类错误（取伪）：H₀ 为假却接受了，概率 = β
样本量固定时，α 减小则 β 增大，不能同时减小。
