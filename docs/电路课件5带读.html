第 1 段 · 理想运放与两个工作区 P1–P3 · 10 分钟

01P1　理想运放的四个指标3 分钟
这一页只讲一件事：把运放理想化，分析才能用虚短虚断
  • 四条理想化：Aod = ∞、Rid = ∞ 且 Ro = 0、KCMR = ∞、BW = ∞
  • 为什么要理想化：只有 Aod = ∞ 时，才能由「uo 有限」推出「uP − uN ≈ 0」→ 这就是虚短
02P2　线性区 vs 非线性区（全章总开关）5 分钟
这一页只讲一件事：有没有负反馈，决定用哪套方法
  • 线性区（有深度负反馈）：uP ≈ uN（虚短）+ iP ≈ iN ≈ 0（虚断）→ 用来算运算、滤波
  • 非线性区（开环或正反馈）：只有虚断，没有虚短！
    · uP > uN → uo = +UOM
    · uP < uN → uo = −UOM
  • 判断口诀：看输出到输入有没有反馈电阻。有 → 线性；没有（开环）或有正反馈 → 非线性
易错：比较器里绝不能写 uP = uN。这是本章最常见的整题作废错误
03P3　运算类型总览（扫过）2 分钟
这一页只讲一件事：时域算运算，频域做滤波
  • 时域：比例、加减、乘除、微分、积分、对数、指数；变换类：V-I、I-V、阻抗变换
  • 频域：滤波
  • 课件原话：运算部分上学期已学，本节只讲滤波电路 → 所以比例/加减/积分/微分只复习公式，不重推
可跳：P3 右下的反相比例电路推导，你上学期做过，直接跳到 P4

第 2 段 · 滤波器到底在滤什么 P4–P7 · 10 分钟

04P4–P5　功能与四大类4 分钟
这一页只讲一件事：让某些频率过、让某些频率死
  • 本质：有源滤波器 = 具有特定频率响应的放大器（所以它一定带运放，一定有增益）
  • 四类：低通 LPF、高通 HPF、带通 BPF、带阻 BEF
  • 理想幅频特性：通带内增益恒为 A0，通带外立刻掉到 0——是个矩形
  • 怎么记四类的名字：名字里的「通」就是能过的频段。低通 = 低频能过
05P6–P7　实际特性：三个关键词6 分钟
这一页只讲一件事：通带、过渡带、阻带
  • 截止频率的定义：增益降到 0.707A0（即下降 3dB）那一点的频率。低通叫 fH，高通叫 fL
  • 三个区：通带（A ≥ 0.707A0）→ 过渡带 → 阻带（A ≤ 0.1A0）
  • 为什么有过渡带：实际电路不可能从「全通」瞬间变「全不通」，中间必然有一段斜坡
  • 滤波器好坏的唯一标准：过渡带越窄越好（阻带增益掉得越快，选择性越好）→ 这就是为什么要做二阶、甚至更高阶
  • 阶数与衰减速度：一阶 = −20dB/十倍频程，二阶 = −40dB/十倍频程

第 3 段 · 低通滤波器（四种里最重要） P8–P15 · 18 分钟

06P8–P9　一阶无源 RC 低通5 分钟
这一页只讲一件事：一个 RC，三个缺点
  • 传递函数：A(jω) = 1/(1 + jω/ω0)，特征频率 ω0 = 1/RC
  • 三个缺点（背下来，这就是有源滤波存在的理由）：
    ① 带负载能力差　② 无放大作用（A0 最大只有 1）　③ 特性不理想、边沿不陡
  • 衰减速率：ω ≫ ω0 时，每十倍频下降 20dB → 记作 −20dB/dec
可跳：P9 右下角的折线近似（波特图画法），只要知道「−20dB/dec」这个结论
07P10–P11　一阶有源低通5 分钟
这一页只讲一件事：加个同相放大器，缺点① ② 解决
  • 通带增益：A0 = 1 + Rf/R1（不再是 1，解决了「无放大」）
  • 截止频率：ωH = ω0 = 1/RC（和增益无关，加运放不改变转折点）
  • 传递函数：A(jω) = (1+Rf/R1)/(1 + jω/ω0)
  • 还剩的缺点：阻带衰减太慢，仍是 −20dB/dec → 所以要上二阶
08P12–P15　二阶有源低通（重点看 P15）8 分钟
这一页只讲一件事：多一级 RC，衰减快一倍，但会自激
  • 结构：两级 RC 串起来 + 同相放大 → 比一阶多一个 C
  • 衰减速率：−40dB/dec（一阶的两倍，过渡带明显变窄）
  • 品质因数：Q = 1/(3 − A0)，其中 A0 = 1 + Rf/R1
  • 三条必须记住的结论：
    · A0 < 3 → 电路稳定（Q 为正）
    · Q = 0.707 → 幅频特性最平坦（巴特沃斯，工程上最常用）
    · A0 ≥ 3 → 自激振荡，滤波器直接坏掉
  • P13 提到的问题：简单二阶在 fH→f0 之间掉得还不够快，所以在 f→f0 附近适当提升增益（就是压控电压源型，P14–P15）来拉近 fH 和 f0
可跳：P12、P14 的传递函数推导过程（两页全是代数），只要结论：A0<3 稳定、Q=0.707 平坦、−40dB/dec

第 4 段 · 高通 = 低通的对偶 P16–P18 · 8 分钟

09P16–P18　对偶关系 + 一阶/二阶高通8 分钟
这一页只讲一件事：R 和 C 换个位置，低通就变高通
  • 对偶怎么做：把低通里的 R ↔ C 互换（串联的 R 换成 C、接地的 C 换成 R），传递函数也跟着对偶
  • 一阶高通：A0 = 1 + Rf/R1，ωL = 1/RC，衰减速率 20dB/dec
  • 二阶高通：衰减速率 −40dB/dec，同样 A0 ≥ 3 会自激，Q = 1/(3−A0)
  • 记忆捷径：低通和高通的公式长得一模一样，只把 fH 换成 fL、把「高频衰减」换成「低频衰减」
可跳：P17 的波特图细节，看图确认「左边掉、右边平」即可

第 5 段 · 带通与带阻 P19–P23 · 10 分钟

10P19–P20　带通 = 低通串高通5 分钟
这一页只讲一件事：两个滤波器串起来，取交集
  • 做法：低通（截止 ω1）串联高通（截止 ω2）→ 只有两者都放行的频段能过
  • 成立条件：ω1 > ω2（低通的截止频率要更高），通带就是 ω2 < ω < ω1
  • 带宽：BW = ω1 − ω2。两个截止频率差得越远，通带越宽
  • 想窄通带怎么办：串联法做不出窄带 → 用 P20 的二阶压控型 BPF
易错：串联的方向别搞反 —— 带通是「低通在前、高通在后」都行，但 ω1 必须大于 ω2，写成 ω1 < ω2 就变成带阻了
11P21–P23　带阻 = 低通并高通（求和）5 分钟
这一页只讲一件事：两个滤波器并联相加，取并集
  • 做法：低通和高通的输出求和 → 低频走低通、高频走高通，中间那段没人管 = 阻带
  • 成立条件：ω1 < ω2（低通截止更低），阻带是 ω1 < ω < ω2
  • 双 T 带阻网络：P22 那个「两个 C 一个 R」的 T 型 + 「两个 R 一个 C」的 T 型并联 →
    · 高频时 C 容抗小 ≈ 短路，走上面的 T 网络
    · 低频时 C 容抗大 ≈ 开路，走下面的 T 网络
    · 中间频段两个网络都不通 → 形成阻带
  • 常见用途：滤掉 50Hz 工频干扰（陷波器）

第 6 段 · 小结 + 识别练习（今天的验收） P24–P27 · 10 分钟

12P24–P25　小结与内容要求4 分钟
这一页只讲一件事：运算和滤波的异同
  • 相同：都引深度负反馈、运放都在线性区、都有虚短虚断、都能用节点电流法解
  • 不同：运算研究时域，滤波研究频域；测试方法也不同（运算测「频率固定时的 Uo–Ui」，滤波测「幅值固定时增益随频率的变化」）
  • 课件原话（P25）：「识别滤波电路即可，习题可不做」。自我检测 二版三版相同，第 9 章 1–3；习题 第 9 章 1–5（选做）
13P26–P27　识别练习（今天必做）6 分钟
这一页只讲一件事：给你电路，说出是什么滤波、几阶
  • P27 的题目就是考试题型：「定性分析下列各电路属于哪种类型滤波电路，并说明是几阶滤波」——一共 5 个电路
  • 做法：先数电容和电阻组成几个 RC 环节（= 阶数），再看电容是「串在信号路上」还是「接到地/反馈」
  • 答案自己先写，再翻 P27 的标注。这一页做对，滤波这块就过关了
识别三步法（考试就靠这三步）

第 1 步 · 数阶数：有几个独立的 RC 环节就是几阶。一阶 = 1 个 C，二阶 = 2 个 C。

第 2 步 · 定类型（看 C 的位置）
· C 串在信号通路上（与输入或级间串联）→ 高通（低频时 C 容抗大，信号过不去）
· C 接在地或反馈支路上（对地旁路）→ 低通（高频时 C 容抗小，信号被旁路掉）
· 一个串、一个接地，且两级串联 → 可能是带通
· 双 T 网络（两个 C 一个 R + 两个 R 一个 C 并联）→ 带阻

第 3 步 · 看有没有运放：有运放 = 有源（有增益、带载能力强）；只有 R 和 C = 无源。

一句话口诀：「串高通、地低通、串加地是带通、双 T 是带阻」

第 7 段 · 比较器基础 P28–P33 · 15 分钟

14P28–P29　非线性区的三条铁律5 分钟
这一页只讲一件事：比大小，不看差值
  • uP > uN → uo = +UOM；uP < uN → uo = −UOM
  • 只有虚断（iP = iN = 0），没有虚短
  • 三种接法：开环 → 单限比较器；开环 + 多门限 → 窗口比较器（大纲不要求）；正反馈 → 滞回比较器
  • 为什么必须限幅：±UOM 通常 ±12V 左右，和后面电路的电平不匹配 → 用 R + 双向稳压管 DZ 限成 ±UZ
可跳：P29 里的窗口比较器（课件注明「不在大纲内，课上不讲」）
15P30–P33　单限比较器 + 阈值怎么算10 分钟
这一页只讲一件事：只有一个门限，比它高就翻
  • 基本型：uI 接一端、UREF 接另一端 → 阈值 UTH = UREF，一个门限
  • 带电阻网络的单限（P33 例题）：阈值不是 UREF 本身，要用叠加定理算：
    ① 由虚断，uP 只由所接电阻分压决定（常为 0）
    ② 用叠加定理写出 uN 关于 uI 和 UREF 的表达式
    ③ 令 uN = uP，解出的 uI 就是 UTH
  • 两个用途：波形变换/整形（把正弦削成方波，P31）和 PWM 脉宽调制（P32）
易错：阈值解出来后一定要写「uI 大于/小于 UTH 时 uo 取什么」，只写一个数不给分。判断方法：随便代一个 uI 试试 uP 和 uN 谁大

第 8 段 · 滞回比较器（考得最多） P34–P40 · 18 分钟

16P34–P37　两个阈值怎么来的10 分钟
这一页只讲一件事：输出自己参与了阈值计算 → 两个门限
  • 核心结构：输出经 R2 反馈到同相端 P（正反馈），这是和单限比较器的唯一区别
  • 算法（三步，固定套路）：
    ① 用叠加定理写出 uP = f(uo, UREF)
    ② 令 uP = uN = uI，解出 uI
    ③ 代 uo = +UZ 得 UTH1；代 uo = −UZ 得 UTH2
  • UREF = 0 的特例（P40 原文，可以直接背）：
    UTH = ±UZ·R1/R2，且 UTH1 = −UTH2（纵轴对称），回差 ΔU = 2UZ·R1/R2
  • UREF 的作用：只平移回差的位置，不改变回差大小（P36 原话）
  • P38 例题：R1=10kΩ、R2=20kΩ、UREF=+3V、±UZ=±6V，答案 UTH1=1.5V、UTH2=7.5V —— 自己按上面三步算一遍，对上了才算会
易错：阈值必须先算 uP，别拿 uN 当阈值。这个电路里 uN 就是 uI（输入），阈值在 P 那一侧
17P35–P36　为什么要有回差4 分钟
这一页只讲一件事：抗干扰
  • 问题：单限比较器在阈值附近，输入稍有噪声，输出就会来回翻转（抖动）
  • 解决：设两个阈值，上升沿翻一次、下降沿翻一次，中间那段「不动」 → 噪声只要小于回差就翻不动
  • 代价：回差越大越抗干扰，但灵敏度越低（输入要变化更多才响应）→ 这是一对矛盾，题目常问「R1 增大回差怎么变」
18P37–P40　电压传输特性怎么画4 分钟
这一页只讲一件事：一个「Z」字形的折线
  • 画法：横轴 uI、纵轴 uO。左边一条水平线在 +UZ（uI 小时输出高），到 UTH1 处竖直掉到 −UZ，往右走到 UTH2 处竖直跳回 +UZ
  • 关键：箭头方向！上升沿在 UTH1 翻、下降沿在 UTH2 翻，两个门限不一样，所以要标箭头，否则图是错的
  • 检验：P39 给了输入三角波 → 输出方波的对照图，你的输出波形应该在两个阈值处才翻转
可跳：P35–P36 两页的「抗干扰示意」图重复度很高，看 P35 一张就够

第 9 段 · 矩形波发生器 P41–P46 · 15 分钟

19P41–P43　电路组成与振荡过程8 分钟
这一页只讲一件事：电容充到阈值就翻，翻了就反着充
  • 两块拼起来：滞回比较器（决定什么时候翻）+ RC 定时电路（决定多久翻一次）
  • 充电过程：uo = +UZ → 经 R 给 C 充电 → uC 上升 → uC 碰到 +UTH 时输出翻到 −UZ
  • 放电过程：uo = −UZ → C 反向充电（放电）→ uC 下降 → 碰到 −UTH 时又翻回 +UZ
  • 注意：这里 uN = uC（电容电压），uP 是阈值 → 和滞回比较器的角色正好对调，别记反
20P44–P46　周期公式与占空比7 分钟
这一页只讲一件事：T = 2RC·ln(1+2R1/R2)
  • 振荡周期：T = 2RC·ln(1 + 2R1/R2)，频率 f = 1/T
  • 占空比 50%：因为充放电走同一条 R，时间常数相同 → 方波对称
  • 怎么改占空比（P45–P46 的讨论）：用电位器 RW + 两个二极管 VD1/VD2 把充电和放电分开走两条路 →
    · 充电时间常数 τ1 = (R′ + rd1 + RW′)C
    · 放电时间常数 τ2 = (R″ + rd2 + RW″)C
    · D = τ1/(τ1+τ2) × 100%
  • 两个二极管的作用：让电流充和放走不同的电阻路径 → 两条路阻值不同 → 占空比可调
易错：ln 里面是 1 + 2R1/R2，不是 1 + R1/R2。R1 是接到输出（±UZ）的那只，R2 是接到地的那只

第 10 段 · 三角波与锯齿波 P47–P55 · 18 分钟

21P47–P48　为什么不能「矩形波 + 积分」5 分钟
这一页只讲一件事：开环积分会跑偏饱和
  • 想法：方波积分应该得到三角波 —— 理论上对
  • 实际不行：矩形波的 +UZ 和 −UZ 不可能完全对称（UZ1 ≠ UZ2），积分器会累积直流偏移 → 输出一路偏上去 → 运放饱和，波形废掉
  • 正确做法（P49）：用同相滞回比较器 + 积分器闭环，让积分器的输出反过来控制比较器的翻转 → 自动纠正偏移
22P49–P51　三角波电路与参数8 分钟
这一页只讲一件事：两个运放互相咬住，自己振荡
  • 组成：A1 = 滞回比较器（输出 uo1 是方波，±UZ）；A2 = 积分器（输出 uo 是三角波）
  • 闭环关系：uo 反馈到比较器的 P 端当阈值；uo1 送进积分器积分 → 方波↔三角波互相锁死，形成稳定振荡
  • 三角波幅值：Uom = (R1/R2)·UZ
  • 振荡周期：T = 4R1R4C/R2（R4 是积分器的输入电阻）
  • 波形关系：uo1 是方波、uo 是三角波，两者同周期，三角波的峰谷正好对应方波的跳变时刻
可跳：P50 的 uP 表达式推导，只记「阈值由 uo 和 UZ 共同决定」这个结论
23P52–P55　怎么变成锯齿波5 分钟
这一页只讲一件事：让充电和放电快慢不一样
  • 方法一（P52–P54）：积分器输入串电位器 RW + 两个二极管 → 正负半周走不同阻值 → 积分斜率不同 → 三角波变锯齿波
  • 方法二（P55）：给积分器叠加一个直流 US（由 VCC 分压得到）→ 充电电压 (+UZ−US) 和放电电压 (−UZ−US) 不等 → 斜率不等
  • 两种方法的共同本质：让上升和下降的速率不同，波形就不对称了
  • 锯齿波的特点：周期 T = T1 + T2，其中 T1、T2 分别是缓升段和陡降段

必记点汇总（14 条）

1
线性区：虚短 + 虚断；非线性区：只有虚断
2
非线性区判据：uP>uN → +UOM；uP<uN → −UOM
3
截止频率定义：增益降到 0.707A0（−3dB）处的频率
4
一阶：−20dB/dec　　二阶：−40dB/dec　　（阶数越高过渡带越窄）
5
一阶有源低通：A0=1+Rf/R1，ωH=1/RC
6
二阶：Q=1/(3−A0)；A0<3 稳定，Q=0.707 最平坦，A0≥3 自激
7
高通 = 低通对偶（R↔C 互换），ωL=1/RC
8
带通：低通串高通，ω1>ω2　　带阻：低通并高通求和，ω1<ω2
9
单限比较器：一个阈值，UTH 由 uP=uN 解出
10
滞回比较器：正反馈，代 uo=±UZ 分别得 UTH1、UTH2
11
UREF=0 时：UTH=±UZR1/R2，回差 ΔU=2UZR1/R2
12
矩形波：T = 2RC·ln(1+2R1/R2)，占空比 50%
13
三角波：Uom=(R1/R2)UZ，T=4R1R4C/R2
14
锯齿波 = 让充放电时间常数不同（电位器+二极管 或 叠直流 US）
