数学竞赛 · 非数学 A 类

高数公式与题型总结 初赛只考高等数学 ｜ 150 分钟 / 100 分 ｜ 目标省二

省二意味着什么：5–6 道大题里稳定做出 3 道。省二和省三的差距不在压轴题，在基础题的手速和准确率。
所以这份总结只列真正会考的，偏门技巧一概不收——你的时间不够。

一、极限（必拿分）

七个等价无穷小（x→0）

sin x ~ x　　tan x ~ x　　arcsin x ~ x　　arctan x ~ x
1−cos x ~ x²/2　　ln(1+x) ~ x　　ex−1 ~ x
(1+x)α−1 ~ αx　　x−sin x ~ x³/6　　tan x−x ~ x³/3
后两个是常考的「三阶」等价，遇到 sin 减 x 直接用，能省一半时间

泰勒展开（三个必背）

ex = 1 + x + x²/2! + x³/3! + o(x³)
sin x = x − x³/3! + x⁵/5! − o(x⁵)
ln(1+x) = x − x²/2 + x³/3 − o(x³)

题型套路

  • 0/0 与 ∞/∞：先等价无穷小替换化简，再洛必达。直接洛必达往往越算越乱。
  • 1∞ 型：必用 lim uv = elim v(u−1)，不要硬套洛必达。
  • ∞−∞ 型：通分或倒代换（令 t = 1/x）。
  • 0·∞ 型：把其中一个写成倒数移到分母。
  • 含根号的差：分子有理化。
易错：等价替换只能用于乘除因子，加减项里替换会出错。这是最高频的失分点。

二、导数与中值定理

三个中值定理（考法固定）

拉格朗日
f(b)−f(a) = f'(ξ)(b−a)
证不等式、估界时用
柯西
[f(b)−f(a)]/[g(b)−g(a)] = f'(ξ)/g'(ξ)
两个函数同时出现时优先想到它
罗尔
f(a)=f(b) ⟹ ∃ξ, f'(ξ)=0
证「存在一点导数为零」的题，先造辅助函数

辅助函数的造法（证明题关键）

  • 要证 f'(ξ) + f(ξ) = 0 → 造 F(x) = exf(x)
  • 要证 f'(ξ) − f(ξ) = 0 → 造 F(x) = e−xf(x)
  • 要证 ξf'(ξ) + f(ξ) = 0 → 造 F(x) = x·f(x)
  • 要证 f'(ξ) = k → 直接拉格朗日，或造 F(x) = f(x) − kx

导数应用

  • 单调性 / 极值：f' 变号处是极值点
  • 凹凸性：f'' > 0 凹（下凸），f'' < 0 凸
  • 拐点：f'' 变号处，不是 f''=0 处
  • 渐近线：水平 lim f(x)、垂直 f→∞ 处、斜的算 lim f(x)/x = k

三、积分（分值最大）

不定积分三板斧

① 凑微分
∫f(ax+b)dx = (1/a)∫f(u)du
见到 f(kx+b) 先想这个，能解决一半的题
② 分部积分
∫u dv = uv − ∫v du
选 u 的顺序：反、对、幂、指、三（谁在前谁当 u）
③ 换元
含 √(a²−x²) → x = a sin t；含 √(a²+x²) → x = a tan t

定积分技巧

对称区间
∫−aa f(x)dx = 2∫0a f(x)dx（f 为偶）　；　= 0（f 为奇）
看到对称区间先判断奇偶，能省大量计算
华里士公式（点火公式）
∫0π/2 sinnx dx = (n−1)!!/n!! × (π/2 若 n 偶)
高频，背下来直接写答案
变上限积分求导
d/dx ∫aφ(x) f(t)dt = f(φ(x))·φ'(x)
易错：反常积分要先判断收敛性再算。∫1∞ 1/xp dx 只有 p>1 收敛。

四、多元微分与重积分

偏导与全微分

dz = (∂z/∂x)dx + (∂z/∂y)dy
复合函数链式法则
z=f(u,v), u=u(x,y), v=v(x,y)
∂z/∂x = fu·ux + fv·vx，别漏项

二重积分

  • 直角坐标：先画区域图，再定积分次序。次序选错会算不出来。
  • 交换次序：画出区域，从另一个方向重新切。这是常考题型。
  • 极坐标：区域是圆或圆环时用。dxdy = r dr dθ，别漏 r。

极值

无条件极值
令 fx=0, fy=0 求驻点，再用 AC−B² 判别
A=fxx, B=fxy, C=fyy；AC−B²>0 且 A>0 极小，A<0 极大；<0 非极值
条件极值
拉格朗日：L = f + λφ
三个方程解出 x, y, λ

五、曲线与曲面积分（A 类必看）

格林公式
∮L Pdx+Qdy = ∬D (∂Q/∂x − ∂P/∂y)dxdy
L 取正向（逆时针）。不是闭曲线要先补线
高斯公式
∯Σ P dydz+Q dzdx+R dxdy = ∭Ω (∂P/∂x+∂Q/∂y+∂R/∂z)dV
Σ 取外侧。曲面不闭要先补面
两类曲线积分的区别（最容易混）
· 第一类（对弧长）：∫L f ds，与方向无关
· 第二类（对坐标）：∫L Pdx+Qdy，与方向有关，反向变号

六、级数

判敛（按顺序试）

  • 先看通项是否趋于 0——不趋于 0 直接发散
  • p 级数：Σ1/np，p>1 收敛
  • 比值法：lim|an+1/an| = ρ，ρ<1 收敛
  • 交错级数：莱布尼茨（递减 + 趋于 0）
幂级数收敛半径
R = 1/lim|an+1/an|
端点要单独判断——这是必考细节
三个必记展开
1/(1−x) = Σxn　　ex = Σxn/n!　　ln(1+x) = Σ(−1)n−1xn/n
求和函数题就是靠这三个往回收

考场时间分配

150 分钟 / 100 分，建议这样切：
· 0–40 分钟：填空 + 选择，会做的立刻写，卡住超过 5 分钟就跳
· 40–110 分钟：常规大题，按「会做的先做」原则，不按题号顺序
· 110–140 分钟：压轴题能写几步写几步，公式摆上去也有分
· 140–150 分钟：检查计算，重点看符号和常数
省二的关键不是做出压轴题，是基础题一分不丢。把「极限 + 积分 + 多元」这三块练到不假思索，就已经够省二了。
