⓪ 课件 1–2 · 半导体二极管 1 小时速览

47 页课件，你只需要看 4 个地方：二极管三种等效模型、稳压管、半波整流波形。其余（本征半导体、共价键、载流子浓度）属于背景知识，考不到计算。

0
二极管与稳压管：只抓三个模型 + 一个参数
课件 2 · P30–P44
▶

核心概念

  • PN 结单向导电：正偏导通（正向压降硅管 0.6~0.7V，锗管 0.3V），反偏截止（只有极小的反向饱和电流）。
  • 三个等效模型，按信号幅度选：信号幅度 ≫ 0.7V 用理想模型（当开关）；一般工程计算用恒压降模型（串一个 0.7V 电池）；要求精确时用折线模型（串 0.7V + 动态电阻 rD）。
  • 稳压管：工作在反向击穿区。它的"稳压"不是不坏，而是只要电流限制在 IZmin ~ IZmax 之间，击穿就是可逆的。

必背公式

稳压管限流电阻
R = (UI − UZ) / (IZ + IL)
取 IZ 的中间值算。校验：IZmin ≤ IZ ≤ IZmax
半波整流输出平均值
UO(AV) = 0.45U2
U2 是变压器二次侧有效值。桥式是 0.9U2
二极管最大反向电压
URM = √2 · U2
选管子时耐压要留 1.5~2 倍余量
例 1｜稳压管电路求限流电阻
UI = 12V，稳压管 UZ = 6V，IZ = 10mA，负载 RL = 1kΩ。求限流电阻 R。
  1. 先算负载电流：IL = UZ / RL = 6V / 1kΩ = 6mA
  2. 总电流 = 稳压管电流 + 负载电流：I = 10 + 6 = 16mA
  3. 限流电阻上要降掉的电压：UR = UI − UZ = 12 − 6 = 6V
  4. R = UR / I = 6V / 16mA = 375Ω（取标称值 360Ω 或 390Ω）
三个高频错点
① U2 是有效值不是峰值。题目给"u2 = 20√2 sinωt V"时，U2 = 20V，峰值才是 28.3V。
② 稳压管反接。它的符号箭头方向和普通二极管相反，正常工作时电流从阴极流向阳极。
③ 整流二极管平均电流不等于负载电流。桥式整流里每个管子只导通半个周期，ID(AV) 是 IL 的一半。

① 课件 3 · 三极管及其放大电路 最重 · 3 小时

90 页，占整门课将近三分之一的分量。这一章的「共射放大电路分析」是整门课的地基——后面运放、稳压全都建立在它上面。三天拆成：Day 1 原理 + 静态，Day 2 动态（微变等效），Day 3 分压偏置 + 失真 + 共集共基。

1
Day 1 · BJT 原理与特性曲线：先搞懂"为什么能放大"
课件 3 · P2–P29
▶

核心概念

  • BJT 是电流控制电流源（CCCS），FET 是电压控制电流源（VCCS）。这句话是两者的分水岭。
  • 放大的外部条件（NPN）：发射结正偏（VB > VE）+ 集电结反偏（VC > VB）。两个条件缺一不可，这是判断"能不能放大"的唯一标准。
  • 内部机理一句话：发射区高掺杂 → 大量电子注入基区 → 基区薄、复合少 → 绝大部分电子被集电结电场"拉"到集电区 → 很小的 IB 控制很大的 IC。
  • 三个工作区：截止（发射结反偏，IC≈0）、放大（正偏 + 反偏，IC=βIB）、饱和（两个结都正偏，UCE≈UCES≈0.3V，IC 不再随 IB 增大）。

必背公式

电流关系
IC = βIB　　IE = (1+β)IB = IC + IB
β 一般 20~200。注意 IE 比 IC 大一点点，别写成相等
工作区判别（NPN）
UBE < 0.5V → 截止
UCE > 1V → 放大
UCE < 0.3V → 饱和
算完 UCE 后必须回头判断假设是否成立
共射特性曲线
输入：iB = f(uBE) | UCE=常数
输出：iC = f(uCE) | IB=常数
输入曲线像二极管正向特性；输出曲线分三个区、略微上翘
最容易错的地方：判断 PNP 管的工作状态时，所有电压符号反过来——发射结正偏是 VE > VB，集电结反偏是 VB > VC。每年都有人在这里翻车。

Day 2 · 共射放大电路：静态 Q + 微变等效（整门课第一大题）
课件 3 · P30–P56
▶
这一节必须练到"不看公式能默写"。模电期末大题有极大概率就是这一套：给一个共射电路 → 求 Q → 画微变等效 → 求 Au / Ri / Ro → 问失真。四步一气呵成。

第一步：画直流通路，求静态工作点 Q

  • 直流通路怎么画：电容开路（C1、C2、Ce 全断开），直流电源保留，交流信号源置零。
基本共射（固定偏置）
IBQ = (VCC − UBEQ) / Rb ≈ VCC / Rb
ICQ = βIBQ
UCEQ = VCC − ICQRc
硅管 UBEQ 取 0.7V。Rb 通常几百 kΩ，所以近似成立
分压式偏置（重点）
UB = VCC · Rb2 / (Rb1+Rb2)
IE = (UB − UBE) / Re ≈ IC
UCE = VCC − IC(Rc+Re)
前提：I2 = (5~10)IB，即 UB = (5~10)UBE

第二步：画交流通路 → 微变等效电路

  • 交流通路怎么画：耦合电容和旁路电容短路，直流电源 VCC 对交流短路接地。
  • 微变等效：把三极管换成一个 rbe（b、e 之间）+ 一个受控电流源 βIb（c、e 之间）。
rbe —— 全章最关键的一个数
rbe = rbb' + (1+β)·26mV / IE(mA)
rbb' = 100~300Ω，题目不给就取 200Ω。IE 单位必须是 mA
电压放大倍数
Au = −βR'L / rbe
R'L = Rc ∥ RL。负号 = 反相，别丢
输入电阻
Ri = Rb ∥ rbe ≈ rbe
Rb 几百 kΩ，并联后基本等于 rbe
输出电阻
Ro = Rc
求法：信号源置零、负载断开，从输出端看进去
考虑信号源内阻时
Aus = Au · Ri / (Ri + Rs)
Rs 越大，Aus 衰减越多 → 所以希望 Ri 大
例 2｜完整四步走（课件 P54–P56 原题）
VCC = 12V，Rb = 300kΩ，Rc = 3kΩ，RL = 3kΩ，rbb' = 200Ω，β = 50。
求：① 静态工作点 Q；② Au、Ri、Ro；③ 最大不失真输出幅度；④ 若出现截止失真该调哪个元件。
  1. 求 Q：IBQ = (12 − 0.7)/300k ≈ 40μA；ICQ = 50 × 40μA = 2mA；UCEQ = 12 − 2mA × 3kΩ = 6V。
    → 检查：UCEQ = 6V > 1V，放大区假设成立 ✓
  2. 算 rbe：rbe = 200 + 51 × 26mV / 2mA = 200 + 663 = 863Ω ≈ 0.863kΩ
  3. 求 Au：R'L = 3k ∥ 3k = 1.5kΩ，Au = −50 × 1.5k / 0.863k = −87
  4. 求 Ri、Ro：Ri = 300k ∥ 0.863k ≈ 0.863kΩ；Ro = Rc = 3kΩ
  5. 最大不失真输出：Uommax = min[UCEQ − UCES, ICQ·R'L] = min[6 − 0.3, 2×1.5] = min[5.7, 3] = 3V
  6. 截止失真：Q 点偏低（靠近截止区）→ 应减小 Rb，让 IBQ 增大、Q 点上移。
    记忆法：截止失真 = Q 太低 = IB 太小 = Rb 太大 → 减小 Rb
四个必扣分的细节
① rbe 里 IE 要用 mA。用 A 代入会算出天文数字。
② Au 的负号不能丢。共射是反相放大，丢负号直接扣分。
③ R'L 别忘了并 RL。题目给了 RL 就必须并联，没给才是 Rc。
④ 求 Ro 时负载要断开。Ro = Rc，不含 RL——这是"从输出端看进去"的定义决定的。

Day 3 · 分压偏置、失真判断、共集共基比较
课件 3 · P57–P89
▶

为什么要分压偏置

  • 温度升高 → UBE 减小、β 增大、ICEO 增大 → IC 增大 → Q 点上移 → 容易饱和失真。固定偏置电路对此毫无抵抗力。
  • 分压偏置的稳定过程（背下这条链）：T↑ → IC↑ → IE↑ → UE = IERe↑ → UBE = UB − UE↓ → IB↓ → IC↓。本质是直流负反馈。
  • 旁路电容 Ce 的作用：它让 Re 对交流短路。没有 Ce 时，Re 会大幅降低 Au（因为 Au = −βR'L/[rbe+(1+β)Re]）；有了 Ce，Au 恢复到 −βR'L/rbe。Ce 不影响 Q，只影响动态参数——这句话是简答题常客。

失真的判断与消除

失真类型波形特征Q 点位置调节方法
截止失真输出电压顶部削平（NPN 共射）Q 点偏低，靠近截止区减小 Rb（增大 IB，Q 上移）
饱和失真输出电压底部削平Q 点偏高，靠近饱和区增大 Rb（减小 IB，Q 下移）
最大不失真输出幅度
Uommax = min[UCEQ − UCES, ICQ·R'L]
取两者中较小的：前者是"向下能摆多少"（饱和），后者是"向上能摆多少"（截止）

三种组态比较（只要"了解"，但比较表必须背）

性能共射共集（射极跟随器）共基
Au大（几十~几百），反相≈ 1（略小于 1），同相大，同相
Aiβ1+ββ/(1+β) ≈ 1
Ri中（几百Ω~几千Ω）大（几十 kΩ 以上）小（几Ω~几十Ω）
Ro中（Rc）小（几Ω~几十Ω）大（Rc）
频响差较好好（频带宽）
典型用途电压放大缓冲、跟随、隔离高频放大
共集（射极输出器）
Au = (1+β)R'L / [rbe+(1+β)R'L] ≈ 1
Ri = Rb ∥ [rbe+(1+β)R'L]
Ro = Re ∥ [rbe+R's]/(1+β)
R'L = Re∥RL；R's = Rs∥Rb
共基
Au = +βR'L / rbe
Ri = Re ∥ rbe/(1+β)
Ro = Rc
Au 是正的（同相）——这是和共射唯一的符号差别

② 课件 4 · 场效应管及其放大电路 1 小时

只有 24 页，是五份要补的课件里最轻的。核心就一句：FET 是电压控制，输入电阻极高。共源放大的分析和共射完全同构，只是把 rbe 换成 ∞、把 βIb 换成 gmUgs。

4
MOSFET 特性 + 共源放大
课件 4 · P1–P24
▶

核心概念

  • N 沟道增强型 MOSFET：UGS > UGS(th)（开启电压）时才形成导电沟道。UGS = 0 时没有沟道、不导通——这是"增强型"的含义。
  • 为什么输入电阻那么高：栅极和沟道之间隔着一层 SiO2 绝缘层，栅极电流几乎为零（10⁻⁹ A 级）。所以 Ri 可达 10⁹~10¹² Ω。
  • 转移特性描述 ID 与 UGS 的关系；输出特性描述 ID 与 UDS 的关系，分可变电阻区、恒流区（放大区）、击穿区。
  • 放大条件：工作在恒流区（饱和区），即 UGS > UGS(th) 且 UDS > UGS − UGS(th)。

必背公式

增强型 MOSFET 转移特性
ID = IDO(UGS/UGS(th) − 1)²
IDO 是 UGS = 2UGS(th) 时的漏极电流
共源放大（对应共射）
Au = −gm(Rd ∥ RL)
Ri ≈ Rg（极大）
Ro = Rd
和共射一一对应：rbe → ∞，βIb → gmUgs
跨导
gm = ΔID / ΔUGS
单位 mS（毫西门子）。相当于 BJT 的 β

BJT 与 FET 对比（课件 P22 的内容，简答题爱考）

对比项BJT（三极管）FET（场效应管）
控制方式电流控制（IB 控 IC）电压控制（UGS 控 ID）
载流子两种（电子 + 空穴）一种（多子）
输入电阻低（kΩ 级）极高（10⁹ Ω 以上）
噪声较大小
温度稳定性较差（有热失控风险）好（有负温度系数）
缺点—易被静电击穿，存放要短接栅极
课件原文：P24 学习要求写的是「了解共漏、共栅组态的电路构成和性能比较」。所以共漏（相当于共集，Au≈1、Ri 大、Ro 小）和共栅只需知道结论，不用推公式。

5
运放的两个工作区：线性区 vs 非线性区（一切分析的起点）
课件 5 · P1–P3
▶
工作区条件能用什么不能用什么典型电路
线性区深度负反馈虚短（uP=uN）+ 虚断（iP=iN=0）—比例、加减、积分、有源滤波
非线性区开环或正反馈只有虚断（iP=iN=0）虚短不成立电压比较器、非正弦波发生
非线性区的输出判据（唯一要记的）
uP > uN → uO = +UOM
uP < uN → uO = −UOM
输出端接稳压管时，±UOM 换成 ±UZ
理想运放指标
Aod=∞　Rid=∞　Ro=0
KCMR=∞　BW=∞
线性区非常窄（一般 < 1.5mV），所以开环必饱和
最常见的致命错误：在比较器电路里写"uP = uN"。比较器是开环或正反馈，虚短绝对不成立。只有虚断成立。这一条错了，后面全错。
6
有源滤波器：只需要"能识别"
课件 5 · P4–P27
▶
课件原文（P25）：「识别滤波电路即可（内容以课件为主，识别课件中讲过的滤波器即可，习题可不做）。自我检测：第 9 章 1-3。」
→ 也就是说：不用推传递函数，不用算截止频率，只要看图能说出是低通还是高通、一阶还是二阶。

识别口诀（这个比背公式管用）

  • 看电容和电阻的位置：电容串联在信号通路里 → 直流和低频过不去 → 高通。电容并在反馈回路或对地 → 高频被旁路掉 → 低通。
  • 数电容个数：一个电容 = 一阶，两个电容 = 二阶。阶数越高，过渡带越陡、滤波特性越接近理想。
  • 带通 / 带阻：低通和高通串联 → 带通；并联（或用一个二阶电路）→ 带阻。
一阶有源低通（课件 P10）
A0 = 1 + Rf/R1　　ω0 = 1/(RC)
A(jω) = A0 / (1 + jω/ω0)
A0 = 通带增益（同相比例）；ω0 = 特征频率 = 截止频率

电压比较器：单限 + 滞回（本节最重要）
课件 5 · P28–P40
▶

单限比较器

  • 结构：运放开环，一端接 uI，另一端接参考电压 UREF。
  • 阈值：只有一个，UTH = UREF。uI 越过它就翻转。
  • 输出限幅：输出端接 R + 稳压管（或两个背靠背稳压管），把 ±UOM 限制成 ±UZ，方便和数字电路接口。
  • 输入保护：输入端并联两个反接的二极管，防止差模电压过大损坏输入级。
  • 用途：波形变换（正弦 → 方波）、脉宽调制（PWM）。
例 3｜阈值不是 UREF 的情况（课件 P33 原题）
uI 经 R1、UREF 经 R2 都接到反相端 N，同相端 P 接地（uP = 0）。求阈值 UTH。
  1. 先写 uP：直接接地，uP = 0
  2. 用叠加定理写 uN：uN = uI·R2/(R1+R2) + UREF·R1/(R1+R2)
    （两个电阻分压，谁的电阻在对侧就乘谁）
  3. 令 uN = uP = 0，解出 uI 就是阈值：UTH = −(R1/R2)·UREF
  4. 结论：阈值大小和符号都由分压比决定，不是简单地等于 UREF。所以考试必须现场推，不能背。

滞回比较器（施密特触发器）

  • 结构：运放引入正反馈（输出经 R 接回同相端），所以输出只有 ±UZ 两个状态。
  • 两个阈值：输出为 +UZ 时对应一个阈值，为 −UZ 时对应另一个。两个阈值之差叫回差（滞回电压）ΔU。
  • 为什么抗干扰强：输入信号在阈值附近抖动时，只要抖动幅度小于 ΔU，输出就不会反复翻转。这是单限比较器做不到的。
同相滞回比较器（课件 P37，已验证）
UTH1 = (R1+R2)/R2 · UREF − R1/R2 · UZ
UTH2 = (R1+R2)/R2 · UREF + R1/R2 · UZ
UREF = 0 时，UTH = ±R1UZ/R2，关于纵轴对称
回差
ΔU = UTH2 − UTH1 = 2R1UZ / R2
同相：ΔU = 2R1UZ/R2。反相结构的系数是分压比，现场推
例 4｜同相滞回比较器求阈值（课件 P38 原题）
R1 = 10kΩ，R2 = 20kΩ，UREF = +3V，稳压管限幅 ±UZ = ±6V。求两个阈值和回差，并画电压传输特性。
  1. UTH1 = (10+20)/20 × 3 − 10/20 × 6 = 4.5 − 3 = 1.5V
  2. UTH2 = (10+20)/20 × 3 + 10/20 × 6 = 4.5 + 3 = 7.5V
  3. ΔU = 7.5 − 1.5 = 6V（也可以用 2R1UZ/R2 = 2×10×6/20 = 6V 校验 ✓）
  4. 画传输特性：横轴 uI、纵轴 uO。uI 从负往正走，越过 7.5V 时 uO 由 +6V 跳到 −6V；uI 从正往负走，越过 1.5V 时 uO 由 −6V 跳到 +6V。箭头方向相反，这就是"回差"
画传输特性时的三个坑
① 两个阈值的方向要标箭头。只画一个矩形框不标箭头，等于没画。
② 输出是 ±UZ 不是 ±UOM。接了稳压管就以 UZ 为准。
③ 阈值可能不在纵轴两侧。像例 4 两个阈值都是正的（1.5 和 7.5），说明特性整体右移了——因为 UREF 不为零。别默认"一正一负"。

课件 P48 专门讲了一个"为什么"：为什么不用「矩形波 + 积分电路」直接产生三角波？因为矩形波的正负幅度如果不相等（UZ1 ≠ UZ2），积分后会产生直流偏移，最终把运放推到饱和，三角波就没了。所以要用滞回比较器 + 积分器闭环的结构，让它自己稳定在对称状态。

串联型稳压电路的四个组成部分（必考简答）

  • 基准电压源（稳压管 + 限流电阻）——提供稳定的 UZ
  • 调整管（T）——串联在输入和输出之间，靠改变 UCE 来稳压
  • 取样电路（R1、R2、RP 分压）——把 UO 的一部分取出来当反馈 Uf
  • 误差放大器（A）——比较 Uf 和 UZ，放大差值去控制调整管

稳压的实质是电压负反馈。背这条链：UI↑ → UO↑ → Uf↑ → (UZ−Uf)↓ → 调整管基极电流↓ → UCE↑ → UO↓。最终 UO 基本不变。

输出电压（调节范围）
UO = UZ · (R1+R2+RP) / (R2+RPa)
RPa 是电位器下半部分的阻值。滑到下端 RPa=0 → UO 最大；滑到上端 RPa=RP → UO 最小
三端可调 CW317
UO = 1.25 × (1 + R2/R1)
1.25V 是内部基准。CW337 是负压版本，公式取负
三端固定 W78xx / W79xx
W7805 → +5V　W7812 → +12V
W7905 → −5V　W7912 → −12V
78 = 正压，79 = 负压，xx = 电压值。引脚：1 输入 / 2 公共 / 3 输出
串联稳压的成立条件（课件 P24 的四个因素）
① UI > UO，且调整管的 UCE > UCES，否则调整管退出线性区，失去调节能力。
② 基准电压 UZ 越稳定越好（UZ 和 Uf 的差值是误差信号）。
③ 误差放大器零点漂移越小越好。
④ 误差放大器增益 Au 和反馈系数 Fu 越大，稳压性能越好。

数制与码制：会转换、认得出 8421BCD 和格雷码
课件 7 · P6–P18
▶

核心概念

  • 数制三要素：数码、基数、位权。二进制基数 2、八进制 8、十六进制 16。
  • 8421BCD 码：用 4 位二进制表示 1 位十进制数。它不是二进制数——(1001)8421BCD = 9，而 (1001)2 = 9 只是巧合；但 (0001 0010)8421BCD = 12，而 (00010010)2 = 18。这是最经典的陷阱题。
  • 余 3 码 = 8421BCD + 3（0011）。格雷码：相邻两个码只有 1 位不同，用于避免代码转换时产生过渡噪声。
  • ASCII 码：7 位，128 个字符。1000001 = 'A'。
课件 P14 的对比题值得记一下：(100010010011)B = 2195（当二进制算）；(100010010011)8421BCD = 893（按每 4 位一组读）。同一个 0/1 串，标注不同结果差 10 倍以上。

最小项与卡诺图：数电最稳的送分题
课件 7 · P44–P66
▶

最小项

  • 定义：n 变量的最小项是包含全部 n 个因子的乘积项，每个变量以原变量或反变量形式出现且仅出现一次。n 变量共 2n 个最小项。
  • 编号：把变量按顺序排好，原变量记 1、反变量记 0，得到一个二进制数，其十进制值就是下标。例：ABC' → 110 → m6。
  • 相邻性：两个最小项只有一个因子不同（如 m3=A'BC 和 m7=ABC），相加可消去一个变量。
  • 标准与或式：把真值表中输出为 1 的那些最小项加起来，记作 Y = Σm(...)。

卡诺图化简三步法

  1. 填图：把函数化成最小项之和，在对应格填 1，其余填 0。无关项填 ×。
  2. 画圈：按 2n 个一组圈（1、2、4、8 格）。圈要尽可能大（消掉更多变量）、尽可能少（乘积项最少）。每个圈里至少有一个 1 只被这个圈圈住。
  3. 写式：每个圈写一个乘积项——圈内取值不变的变量保留（1 取原变量、0 取反变量），变化的变量消掉。所有圈相或。
合并规律
2 格 → 消 1 个变量
4 格 → 消 2 个变量
8 格 → 消 3 个变量
2n 格合并消去 n 个变量
卡诺图的"卷边"性质
左右首尾相邻、上下首尾相邻
四个角也两两相邻
四变量图里 m0、m2、m8、m10 可以圈成一个 4 格圈
例 6｜含无关项的卡诺图化简（课件 P62 原题）
化简 Y = Σm(0,1,2,3,5,7) + Σd(4,6)　（四变量 A、B、C、D，d 表示无关项）
  1. 画四变量卡诺图：横轴 AB（00/01/11/10），纵轴 CD（00/01/11/10）。m0 在左上角，按格雷码顺序排。
  2. 填数：m0,m1,m2,m3,m5,m7 填 1；m4,m6 填 ×；其余填 0。
  3. 用无关项补圈：m0,m1,m4,m5 这一行里，m0、m1 是 1，m4、m5 中 m5 是 1、m4 是 × → 把 × 当 1 圈成 4 格，消掉 2 个变量。
  4. 关键判断：无关项"可以当 1，也可以当 0"，哪种能让圈更大就当哪种。如果补上它圈没变大，就干脆当 0，别乱圈。
  5. 结果形如 Y = A' + B'C'D'...（具体项取决于圈法，以实际填图为准）。考试时按图现场圈，不要背这题的答案。
卡诺图四个高频错误
① 圈的大小不是 2n。3 格、5 格、6 格的圈都是错的。
② 有 1 没被圈到。所有 1 都必须圈进去，孤立的 1 也要单独圈一格。
③ 画了无效圈。如果某个圈里的 1 全被别的圈圈过了，这个圈就是多余的，必须删掉。
④ 变量取值搞反。圈内某个变量恒为 0 时取反变量（如 A'），恒为 1 时取原变量（A）。这里反了整道题就废了。
