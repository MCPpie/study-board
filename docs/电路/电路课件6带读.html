第 1 段 · 全章地图 P1–P2 · 8 分钟

01P1　两类稳压电源3 分钟
这一页只讲一件事：线性 vs 开关，本章只考线性
  • 线性稳压：调整管工作在放大区，靠「吃掉多余的电压」来稳压，效率低但纹波小
  • 开关稳压：调整管当开关用，效率高，但课件明说「不在大纲内，课上不讲」
  • 考试范围就是线性，别在开关电源上花时间
02P2　四大环节 ★必背5 分钟
这一页只讲一件事：u1→u2→u3→u4→uo 这条链
  • 变压器：u1（220V）→ u2，把电网电压降到合适值
  • 整流：u2（交流）→ u3（脉动直流）——靠二极管的单向导电性
  • 滤波：u3 → u4（较平滑的直流）
  • 稳压：u4 → uo，抵抗电网波动和负载变化，让输出不变
  • 记法：变压 → 整流 → 滤波 → 稳压，四步顺序不能乱，问答题常直接考这条链
这一页是整章的目录。后面 6.3 整流、6.4 滤波、6.5 稳压，就是这条链的后三段。

第 2 段 · 整流电路 ★数值必考 P3–P13 · 25 分钟

03P3　四个量各用什么表示 ★易错5 分钟
这一页只讲一件事：谁用有效值、谁用平均值、谁用最大值
  • 输入（交流）→ 用有效值 U2 或最大值 √2U2
  • 输出（直流）→ 用平均值 UO(AV)
  • 流过二极管的电流→ 用平均值 ID(AV)
  • 二极管承受的反向电压→ 用最大值 URM
  • 实际二极管有正向压降，整流后幅度会比理论值少 0.6~1V（工程估算时通常忽略）
易错：题目给「u2=20V」指的是有效值；写 URM 时一定要乘 √2，写成 20V 就是错的。
04P4–P5　半波整流的波形5 分钟
这一页只讲一件事：正半周通、负半周断
  • u2 正半周：二极管正偏导通，负载上得到半个正弦波
  • u2 负半周：二极管反偏截止，iO ≈ 0，整个负半周都加在二极管上
  • 所以二极管承受的最大反向电压 = u2 的峰值 = √2U2——这是 URM 的来源
  • 「半个周期有电流」→ 所以叫半波，输出是「缺了一半」的脉动波形
可跳：P5 的波形作图过程，只要能在脑子里画出「一半有、一半平」就够了
05P6–P7　半波三个参数 ★必背8 分钟
这一页只讲一件事：0.45、0.45、√2 这三个数
  • UO(AV) = 0.45U2（输出电压平均值）
  • ID(AV) = IO(AV) = 0.45U2/RL（二极管正向平均电流）
  • URM = √2U2（最大反向电压）
  • 0.45 怎么来的：一个周期只通了半个周期，所以是「全波平均值 0.9」的一半
  • 选管原则：耐压要高于 URM，否则反向击穿
半波 ↔ 桥式的换算关系：桥式的 UO 是半波的 2 倍，但 URM 两者相同（都是 √2U2）。这一点最容易记混。
06P8–P11　桥式整流的导通路径8 分钟
这一页只讲一件事：每半个周期都是「一对管」导通
  • 正半周：VD1、VD3 导通，VD2、VD4 截止 → 负载「上正下负」
  • 负半周：VD2、VD4 导通，VD1、VD3 截止 → 负载还是「上正下负」
  • 关键结论：两个半周负载电流方向相同，所以输出是全波脉动波形，不再是「缺一半」
  • 怎么记导通对：对着的那一对——正半周走 VD1→负载→VD3，负半周走 VD2→负载→VD4，画箭头比背表快
  • P11 把四只管子的电流波形画在一起：每个管子只导通了半个周期
可跳：P11 的多波形叠图细节，抓住「每管半周导通、负载全周有电流」即可
07P12–P13　桥式参数 + 整流桥符号 ★必背6 分钟
这一页只讲一件事：0.9、0.45、√2
  • UO(AV) = 0.9U2
  • ID(AV) = 0.45U2/RL = ½·IO(AV)——每个管子只承担负载电流的一半，这是桥式的额外好处
  • URM = √2U2（与半波相同）
  • P13：四个管子做成一体 → 整流桥，符号是菱形 + 两个「~」+「+」「−」，四个端子
  • 桥式 vs 半波：输出电压翻倍、每管电流减半、耐压相同 → 桥式全面占优，实际都用桥式
易错：很多人以为桥式的 URM 是 2√2U2。不是。任一时刻只有两个管子截止，每个截止管承受的反压仍是 √2U2。

第 3 段 · 滤波电路 P14–P18 · 15 分钟

08P14　两种基本形式4 分钟
这一页只讲一件事：C 并联、L 串联
  • 电容 C 并联在负载两端——因为 C 对直流开路、对交流阻抗小，把交流旁路掉
  • 电感 L 串联在负载前面——因为 L 对直流阻抗小、对交流阻抗大，把交流挡住
  • 一句话记：电容「旁路」，电感「扼流」，一个并联一个串联，方向正好相反
09P15–P17　电容滤波 ★核心必考8 分钟
这一页只讲一件事：充放电 + 1.2U2
  • 工作机制：u2 > uC 时二极管导通、C 充电；u2 < uC 时二极管截止、C 通过 RL 放电
  • 空载（RL=∞）：没有放电回路，C 一直保持 → UL = √2U2 ≈ 1.4U2（最大值）
  • 无电容（纯桥式）：UL = 0.9U2（最小值）
  • 工程估算：UL ≈ 1.2U2——正好是 0.9 和 1.4 的平均值，这个 1.2 必背
  • RLC ≥ (3~5)·T/2，T 是电源电压周期。RLC 越大 → 放电越慢 → UL 越高越平
  • 代价：整流管导通时间变短 → 瞬时峰值电流 iD 很大，选管要留余量（P16–P17 的 iD 尖峰波形就是讲这个）
易错：1.2U2 是「有负载、且 RLC 足够大」时的估算值，不是精确值。空载时会升到 1.4U2——所以电容耐压要按 1.4U2 选，这是常考的设计陷阱。
10P18　电感滤波3 分钟
这一页只讲一件事：还是 0.9U2，但适合大电流
  • UO(AV) ≈ 0.9U2（和纯桥式一样，因为 L 对直流相当于短路）
  • IO(AV) = 0.9U2/RL
  • 谐波分量 f 越高，XL=ωL 越大 → 交流大部分降在 L 上 → 输出平滑
  • 适用场合：负载电流较大且变化较大（L 越大、RL 越小，滤波效果越好）
  • 对比：电容滤波适合小电流（输出高但冲击大）；电感滤波适合大电流

第 4 段 · 串联型稳压电路 ★原理必考 P19–P24 · 20 分钟

11P19–P20　四个组成部分 ★必背7 分钟
这一页只讲一件事：基准 + 调整 + 取样 + 比较放大
  • 基准电压源（稳压管 DZ + R）：提供不动的参考 UZ
  • 取样电路（R1、R2、RP 串联分压）：把 Uo 取一部分出来变成 Uf
  • 误差放大器 A：比较 Uf 与 UZ，把差值放大
  • 调整管 T：串在输入与输出之间，受误差放大器控制，改变自己的 UCE
  • 记法：基准、取样、比较、调整——四个字一组，问答题按这四个说就有分
  • 整体关系：UI = UCE + UO——多余电压全被调整管吃掉
12P21–P22　稳压过程 ★最常考的问答题8 分钟
这一页只讲一件事：用箭头链把负反馈走一遍
  • 输入电压升高时：
    UI↑ → Uo↑ → Uf↑ → (UZ−Uf)↓ → A 输出↓ → IB↓ → UCE↑ → Uo = UI − UCE 基本不变
  • 负载电流增大时：
    RL↓ → Uo↓ → Uf↓ → (UZ−Uf)↑ → A 输出↑ → IB↑ → UCE↓ → Uo 回升
  • 本质：电压负反馈（P21 原文就写了这四个字，答题时一定要写出来）
  • 为什么要这么绕：调整管是「用电流控制电压降」的器件，必须靠反馈才知道该吃多少
这两条箭头链背下来就够应付问答题。注意方向别写反：输出低了要让它「多吃少」——Uo↓ → UCE↓。
13P23–P24　输出范围 + 性能因素5 分钟
这一页只讲一件事：RP 调到哪里最大、哪里最小
  • Uo = UZ·(R1+R2+RP)/(R2+RP′)，RP′ 是下臂那一段
  • RP 全在上臂（RP′=0）→ 取样比最小 → Uo(max) = UZ(R1+R2+RP)/R2
  • RP 全在下臂（RP′=RP）→ 取样比最大 → Uo(min) = UZ(R1+R2+RP)/(R2+RP)
  • 四个影响稳压性能的因素（P24 原文四条）：
    ① UI > Uo，且 UCE > UCES，否则调整管进饱和、失去调节能力
    ② 基准 UREF 越稳越好——UREF 变了，差值就不可靠
    ③ 误差放大器零点漂移越小越好（选温度稳定性好的器件）
    ④ 误差放大器放大倍数 Au 和反馈系数 Fu 越大越好

第 5 段 · 三端集成稳压器 P25–P31 · 15 分钟

14P25–P27　78xx 与 79xx ★引脚顺序易错6 分钟
这一页只讲一件事：两个系列的引脚顺序正好相反
  • 三端 = 输入端、输出端、公共端；内部带过流 / 二次击穿 / 热过载保护
  • W78xx（正电压）：1 输入　2 公共　3 输出
  • W79xx（负电压）：1 公共　2 输入　3 输出
  • 型号末两位就是电压：7805=+5V、7809=+9V、7812=+12V、7815=+15V；7905=−5V … 7915=−15V
  • 封装 TO-220，加散热片；C1 抑制高频、C2 改善瞬态
这是本章最阴的一个坑：78 和 79 只有「公共端」和「输入端」位置对调。接线接反 = 直接烧。判断口诀：78 是「进—地—出」，79 是「地—进—出」。
15P28–P29　正负双电源4 分钟
这一页只讲一件事：78 和 79 挂在同一组变压器上
  • u2 正半周：VD1、VD3 导通 → C1 滤波 → 供 +UI1 给 CW78xx → 输出 +UO1
  • u2 负半周：VD2、VD4 导通 → C2 滤波 → 供 −UI2 给 CW79xx → 输出 −UO2
  • 要点：正负两路各自整流、各自滤波、各自稳压，共用一个二次绕组和公共地
  • 用途：运放需要 ± 双电源——正好接上你 10-27 学的运放那一章
可跳：P29 是 P28 的负半周重复说明，扫一眼确认「换成 VD2/VD4」即可
16P30–P31　三端可调 317 / 3375 分钟
这一页只讲一件事：输出 = 1.25V × (1 + R2/R1)
  • CW317（正压可调）：输出端与调整端之间固定 1.25V
    Uo = 1.25 × (1 + R2/R1)（严格式还要加 IAdjR2，一般可忽略）
  • CW337（负压可调）：输出端与调整端之间 −1.25V，公式同理取负
  • 为什么是 1.25V：芯片内部基准就是 1.25V，外部只用两个电阻分压就能设定输出
  • 和固定式的区别：固定式靠换型号改电压，可调式靠改电阻改电压
  • P30–P31 的 C1/C2：防止自激、改善纹波
317 的最小输出就是 1.25V，做不到 0V。要 0V 起调得用别的方案——这是常考的选择题干扰项。
