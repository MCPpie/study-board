P16–P188 分钟

半导体是什么 + 为什么是硅和锗 速览

导电能力介于导体和绝缘体之间。关键逻辑链：四价元素最合适 → 碳、硅、锗、锡都是四价 → 但碳燃点低、锡太活泼 → 最后选硅和锗。

这一段不用背，只要理解「为什么是四价」：因为四价元素要凑成 8 电子稳定结构，正好和邻居共用 4 个价电子形成共价键，晶格结构最规整。

P19–P2312 分钟

本征半导体 + 两种导电机理 核心

这是整门课第一个真正的概念，后面所有器件都建立在「自由电子 + 空穴」这两个载流子上。

逻辑顺序：完全纯净的晶体 → 相邻原子共用价电子形成共价键 → 温度高于 0K 时，有些价电子挣脱束缚变成自由电子，原位留下一个空穴（这叫本征激发）→ 电子和空穴成对出现，数目相等 → 电子遇空穴会填补（复合）→ 一定温度下激发和复合达到动态平衡。

两种导电机理（P22–P23）：自由电子导电（和金属一样，电场下定向移动）；空穴导电（空穴吸引相邻原子的价电子来填补，自己「移动」到那个原子，等效于正电荷在移动）。

必记三条：① 本征激发同时产生自由电子和空穴，成对、数目相等；② 两种载流子：自由电子（负）+ 空穴（正）；③ 空穴导电的本质是「价电子的反向填补」，不是真的有正电荷在跑。
P24–P258 分钟

N 型 / P 型半导体（掺杂） 核心

本征半导体掺入五价元素（磷 P、砷 As）→ 多出一个电子 → N 型，自由电子是多子，空穴是少子。

掺入三价元素（硼 B、镓 Ga、铟 In）→ 缺一个电子 → P 型，空穴是多子，自由电子是少子。

必记：N 型＝掺五价＝多子自由电子；P 型＝掺三价＝多子空穴。「多子 / 少子」这两个词后面会反复出现，现在就要说顺。
P26–P2915 分钟

PN 结的形成 + 单向导电性 全课第一个重点

形成过程（P26）：P 区和 N 区接触 → 浓度差导致多子扩散（P 区的空穴往 N 区跑，N 区的电子往 P 区跑）→ 交界处留下不能移动的离子 → 形成空间电荷区（就是 PN 结）→ 产生内电场，方向阻止扩散 → 扩散和漂移达到平衡。

单向导电（P27–P28），这是本章第一个必考结论：

· 正向偏置（P 接正、N 接负）：外电场削弱内电场 → 结变窄 → 多子扩散加强 → 正向电流大、正向电阻小 → 导通
· 反向偏置（P 接负、N 接正）：外电场加强内电场 → 结变宽 → 少子漂移形成很小的反向电流 → 截止

必记：正偏 → 结变窄 → 导通；反偏 → 结变宽 → 截止。「变窄 / 变宽」是答题时最好用的关键词，比说「电阻变小」更准确。

P29 是这一节的小结页，建议停下来自己复述一遍再往下翻。

P30–P3110 分钟

二极管的结构 + 伏安特性曲线 核心

结构很简单：二极管 = PN 结 + 管壳 + 引线，P 端是阳极，N 端是阴极（符号里三角形指向的那一端是阴极）。

P31 的伏安特性曲线是这张图必须看懂：正向有一段「死区」（电压不够大时不导通），过了死区电流急剧上升；反向电流很小且基本不变（反向饱和电流 IS），到某个电压突然击穿（UBR）。

必记数值：硅管导通压降 0.7V（死区约 0.5V）；锗管 0.3V（死区约 0.1V）。硅 0.7 / 锗 0.3 这两个数，后面每道题都要用，现在就要背死。
P32–P3520 分钟

二极管的三种等效模型 本章最核心 · 必考

这是课件 1 最重要的四页，也是模电的思维方式入门——同一个器件，在不同场合用不同精度的模型去近似。

① 理想模型（P32）：导通时压降为 0，截止时反向电流为 0，相当于一个理想开关。
什么时候用：信号幅值远远大于二极管压降时（比如电源电压 10V，0.7V 可以忽略）。

② 恒压降模型（P33）：导通时压降恒为 UD（硅 0.7V、锗 0.3V），相当于理想二极管串联一个恒压源。
什么时候用：最常用的一个。信号幅值和压降可比时（比如 3V 信号），用它。

③ 小信号模型（P34–P35）：把二极管在工作点 Q 附近看作一个电阻 rd，rd = UT/ID ≈ 26mV / ID(mA)。
什么时候用：分析交流小信号时。关键前提：必须先有一个静态工作点 Q，没有 Q 就没有 rd。

必记：① 三种模型各自的适用场合（这是简答题常客）；② rd = 26mV / ID(mA)，ID 的单位必须是 mA；③ 「先有 Q 点才能算 rd」——这句话在课件 3 讲放大电路时会原封不动地再来一次。
P36–P3910 分钟

整流电路（半波 / 桥式） 只懂概念

半波整流：一个二极管，正半周导通、负半周截止，输出只有一半波形。
桥式整流：四个二极管搭成桥，正负半周都有同方向的电流流过负载，输出全波波形。

这里只要求「看懂原理」，不要背系数。0.45U2、0.9U2、√2U2 这些公式在课件 6（直流电源）里会完整讲一遍，那时再背。现在背了也会忘，而且会和课件 6 的内容打架。

判断标准：能说清楚「正半周哪两个管子导通、负半周哪两个导通」，就算过关。

P418 分钟

二极管开关电路 / 门电路 看一眼

P42–P4312 分钟

稳压二极管 核心 · 必考

稳压管和普通二极管结构一样，用法相反——它工作在反向击穿区。反向电压达到 UZ 后，电流在很大范围内变化而电压几乎不变，这就是「稳压」。

P42 的伏安特性要记住三个位置：UZ（稳定电压）、IZmin（最小工作电流，低于它稳不住）、IZmax（最大工作电流，超过它烧管子）。

P43 的限流电阻计算是这一节唯一可能出计算题的地方。思路是两个极端情况：

· 当输入电压最大、负载电流最小时，稳压管电流最大 → 要求不超过 IZmax → 得到 R 的下限
· 当输入电压最小、负载电流最大时，稳压管电流最小 → 要求不低于 IZmin → 得到 R 的上限

不要死背公式，记住「两个极端」这个思路就行：R 上分掉的电压 = UI − UZ，流过 R 的电流 = IZ + IL，所以 R = (UI − UZ) / (IZ + IL)。把两种极端代进去，就得到 R 的范围。
