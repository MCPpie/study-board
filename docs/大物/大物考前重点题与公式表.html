A2 倍
B1/2
C1/4
D不变
2.1 mol 刚性单原子理想气体在等压过程中吸收的热量，有百分之多少用于对外做功：
A2/5 = 40%
B3/5 = 60%
C2/7 ≈ 28.6%
D1/3 ≈ 33.3%
3.关于可逆绝热过程与绝热自由膨胀，下列说法正确的是：
A两者温度都不变
B两者熵变都为零
C前者熵变为零，后者熵增大
D前者熵增大，后者熵变为零
4.一定量理想气体经一循环过程回到初态，则：
AΔU = 0，净吸热等于对外做的净功
BΔU = 0，所以整个过程既不吸热也不放热
C对外做的净功为零
D熵变为负
展开选择题答案
1. B　λ = kT/(√2·πd²p)，与 T 成正比、与 p 成反比。T 不变、p 加倍 → λ 减半。
易错：别用 λ = 1/(√2πd²n) 时忘记 n 也随 p 变了，两条式子等价，选一条算到底。
2. A　单原子 i = 3，Cp = (5/2)R。W = RΔT，Q = (5/2)RΔT → W/Q = 2/5 = 40%。
易错：这题卷一考的是双原子（2/7），换成单原子就是 2/5。i 变了答案就变，看清分子类型。
3. C　可逆绝热 Qrev = 0 → ΔS = ∫dQ/T = 0。绝热自由膨胀虽 Q = 0，但不可逆，不能套 dQ/T，实际熵增大（等于同温可逆膨胀的 νR ln2）。
4. A　循环回到初态，状态函数变化为零：ΔU = 0、ΔS = 0。由 Q = ΔU + W 得 Q净 = W净。
易错：ΔU = 0 不等于「没有热交换」——一个循环里既吸热又放热，只是净值为 W。

5.2 mol 刚性双原子理想气体，温度从 300 K 升到 400 K。等容过程吸热 Q = ?；若改为等压过程，吸热 Q′ = ?。
6.一卡诺热机低温热源 300 K，效率 40%，则高温热源 T₁ = ? K；若低温不变、要把效率提到 50%，T₁ 需升到 ? K。
7.1 mol 理想气体在 300 K 下等温可逆膨胀，体积变为原来的 3 倍，则 ΔS = ? J/K，ΔU = ?。
展开填空题答案
5.　双原子 i = 5，ΔT = 100 K，ν = 2
等容：Q = νCVΔT = (5/2)×2×8.31×100 = 4.16×10³ J 等压：Q′ = νCpΔT = (7/2)×2×8.31×100 = 5.82×10³ J 两者之差 1.66×10³ J 正是等压过程对外做的功 νRΔT = 2×8.31×100 6.　η = 1 − T₂/T₁ → T₁ = T₂/(1−η)
η = 40%：T₁ = 300/0.6 = 500 K η = 50%：T₁ = 300/0.5 = 600 K 易错：效率每提高 10 个百分点，高温热源要涨 100 K——这就是为什么实际热机效率提升极难。
7.　ΔS = νR ln(V₂/V₁) = 8.31 × ln3 = 8.31 × 1.0986 = 9.13 J/K ΔU = 0（等温，理想气体内能只与 T 有关）

12.（14 分）试从分子动理论角度说明：为什么理想气体的内能只是温度的函数、与体积无关？真实气体在什么条件下会偏离这一结论？
展开计算题答案与解析
8.
(1) η = 1 − T₂/T₁ = 1 − 300/600 = 50% (2) 等温膨胀吸热 = 对外做功：Q₁ = νRT₁ln(V₂/V₁) = 1×8.31×600×ln2 　　= 4986 × 0.6931 = 3.46×10³ J (3) W净 = ηQ₁ = 0.5 × 3.46×10³ = 1.73×10³ J 也可算 W净 = Q₁ − Q₂，其中 Q₂ = νRT₂ln2 = 8.31×300×0.693 = 1.73×10³ J 易错：绝热两段 Q = 0，所以「吸的热」只有等温膨胀那一段；卡诺循环的效率只由两热源温度定，跟 V₂/V₁ 无关。
展开计算题答案与解析
9. 关键：末温 300 K 等于初温 300 K
1→2 等容吸热：p 加倍 → T₂ = 2T₁ = 600 K 2→3 绝热膨胀：T 由 600 K 降到 300 K，Q₂₃ = 0 全过程 ΔU = (5/2)νR(T末−T初) = 0（温度回到原值） Q = Q₁₂ = (5/2)×2×8.31×(600−300) = 1.25×10⁴ J（只有等容段吸热） W = Q − ΔU = 1.25×10⁴ J（全部吸收的热都变成功） 验算：W = W₁₂ + W₂₃ = 0 + [−ΔU₂₃] = (5/2)×2×8.31×300 = 1.25×10⁴ J ✓ 易错：这题最容易错在「以为绝热膨胀温度不变」。可逆绝热膨胀温度一定下降（600→300 K），不变的是绝热自由膨胀。两者别混。
展开计算题答案与解析

展开简答题答案与解析
12. 答题要踩三个点：
① 无势能：理想气体模型忽略分子间相互作用力（除碰撞瞬间），所以分子间没有势能，内能 = 全体分子动能之和。 ② 动能只由 T 定：由能量均分定理，每个自由度平均 (1/2)kT，故 U = (i/2)νRT，只含 T，与 V 无关。 ③ 推论：所以理想气体等温过程 ΔU = 0，绝热自由膨胀温度不变，节流膨胀温度不变。 真实气体的偏离：分子间有引力和斥力，存在分子势能，与分子间距（即体积 V）有关 → U = U(T, V)。只有在高温低压（分子间距远大于分子直径、势能占比可忽略）时才接近理想气体。

① 气体动理论

压强p = nkT = (2/3)n·ε̄k　n = N/V 数密度
平均平动动能ε̄k = (3/2)kT　只与 T 有关，与气体种类无关
自由度 i单原子 3 ｜ 刚性双原子 5 ｜ 刚性多原子 6
内能U = (i/2)νRT = (i/2)pV　理想气体 U 只随 T 变
三种速率vp = √(2RT/M) < v̄ = √(8RT/πM) < √(v̄²) = √(3RT/M)
平均自由程λ = kT/(√2·πd²p) = 1/(√2·πd²n)

② 热力学第一定律

核心式Q = ΔU + W　W 为气体对外做功
热容CV = (i/2)R，Cp = ((i+2)/2)R，γ = Cp/CV
等容W = 0，Q = ΔU = νCVΔT；p/T = 常量
等压W = pΔV = νRΔT，Q = νCpΔT；V/T = 常量
等温ΔU = 0，Q = W = νRT ln(V₂/V₁)；pV = 常量
绝热Q = 0，W = −ΔU = νCV(T₁−T₂)
绝热方程pVγ = 常量，TVγ−1 = 常量　仅可逆绝热可用
循环W净 = ∮p dV = p-V 图封闭面积（顺时针为正）；η = W净/Q吸

③ 热力学第二定律

热机效率η = W/Q₁ = 1 − Q₂/Q₁
卡诺效率η卡 = 1 − T₂/T₁　只由两热源温度决定
制冷系数w = Q₂/W = T₂/(T₁−T₂)　可大于 1
熵变定义ΔS = ∫dQ可逆/T　必须沿可逆路径积分
常用熵变等温 νRln(V₂/V₁) ｜ 等压 νCpln(T₂/T₁) ｜ 等容 νCVln(T₂/T₁)
固液变温ΔS = mc·ln(T₂/T₁)　分几段就加几次
统计意义S = k ln Ω　Ω 为微观状态数
熵增原理孤立系统 ΔS ≥ 0，等号对应可逆过程

五个最容易丢分的坑 考前扫一眼

  • ① 熵增原理只对孤立系统。系统放热时熵会减小，别写「任何过程 ΔS ≥ 0」。
  • ② 「绝热」不等于「温度不变」。可逆绝热膨胀温度降；温度不变的是绝热自由膨胀（Q = 0 且 W = 0 → ΔU = 0）。
  • ③ 循环效率的分母只放吸热项。放热的那部分绝不能进分母。
  • ④ 内能用 i，平均平动动能只用 3。双原子 U 用 5 个自由度，但 ε̄k 永远是 (3/2)kT。
  • ⑤ 熵变遇不可逆过程，必须另设可逆路径。直接用 Q/T 会算出 0，与熵增矛盾。
