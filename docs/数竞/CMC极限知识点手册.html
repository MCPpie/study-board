0使用说明

这份手册按「概念 → 工具 → 数列 → 连续 → 题型 → 易错」六层组织。极限这一章在 CMC 里的特点是：填空题靠它拿分，解答题靠它开胃。它是后面所有章节的地基——导数定义、定积分定义、级数判敛，本质上全是极限。

建议的读法：第一遍通读，不追求全懂；第二遍只看打了「必背」和「陷阱」标记的卡片；考前只看第六节。

一概念地基

1.1　极限的定义

数列极限：∀ε>0, ∃N, 当 n>N 时, |an − a| < ε

函数极限：∀ε>0, ∃δ>0, 当 0<|x−x0|<δ 时, |f(x)−A| < ε

CMC 几乎不考用定义证明极限，但要理解一句话：极限描述的是「趋势」，不是「取值」。函数在 x0 处有没有定义、取什么值，与极限无关。

1.2　极限的四条性质
性质内容
唯一性极限若存在，必唯一
局部有界性极限存在 ⇒ 在去心邻域内有界
局部保号性若 lim f = A > 0，则在某去心邻域内 f(x) > 0
四则运算两个极限都存在时，和差积商的极限等于极限的和差积商
陷阱：四则运算的前提是「两个极限都存在」。很多人在拆开 lim(f−g) 后算出 ∞−∞，就下结论「极限不存在」——其实只是不能拆，原式可能是有极限的。

保号性在求参数时极其好用：由极限的符号可以反推函数在邻域内的符号。

1.3　左右极限陷阱

limx→x0 f(x) 存在 ⟺ f(x0−) = f(x0+)

出现下列信号，必须分左右：

信号在 x=0 处的情况
e1/x右极限 +∞，左极限 0 → 极限不存在
arctan(1/x)右 π/2，左 −π/2 → 极限不存在
|x| / x右 1，左 −1 → 极限不存在
分段函数的分段点按定义分别求
1.4　无穷小与无穷大

无穷小：以 0 为极限的变量。注意它是「变量」，不是「很小的数」。

三条运算性质：

① 有限个无穷小之和仍是无穷小
② 有界函数 × 无穷小 = 无穷小（sin x、arctan x 都有界）
③ 有限个无穷小之积仍是无穷小

陷阱：「有限个」这三个字是考点。无限个无穷小之和不一定是无穷小。
反例：limn→∞ (1n + 1n + ⋯ + 1n)（n 项）= lim 1 = 1，不是 0。

无穷大：|f(x)| 无限增大。无穷大一定无界，但无界不一定是无穷大（如 x sin x）。

1.5　无穷小的阶与比较

设 α, β 都是无穷小，lim α/β = c：

结果关系记号
c ≠ 0同阶无穷小α = O(β)
c = 1等价无穷小α ~ β
c = 0α 是 β 的高阶无穷小α = o(β)
c = ∞α 是 β 的低阶无穷小—

k 阶无穷小：若 lim α/βk = c ≠ 0，则称 α 是 β 的 k 阶无穷小。这是「求 α」类题目的理论基础（见 5.2）。

做题第一步永远是判断类型。类型决定方法，不是反过来。

类型转化方式主力工具

∞ / ∞直接处理洛必达、抓大头（同除最高次）

口诀：乘除换等价，加减上泰勒；阶数看分母，抵消再升阶。
2.2　等价无穷小替换陷阱

能换的地方：整个式子的乘除因子。也就是「整体乘以它」或「整体除以它」的位置。

不能换的地方：加减项。原因是抵消——等价无穷小只保留最低阶非零项，两个最低阶一减就没了，被丢掉的高阶项恰恰是答案。

经典反例：limx→0 (tan x − sin x)/x³
错误做法：tan x ~ x、sin x ~ x，得 (x−x)/x³ = 0。错。
正确做法：展开到三阶，(x + x³/3) − (x − x³/6) = x³/2，答案 1/2。

一句话理解：等价无穷小 = 泰勒展开去掉所有高阶项后剩下的最低阶那一项。它不是另一个公式，是泰勒的特例。

2.3　麦克劳林展开（泰勒在 0 处）必背
函数展开式（到三阶）
ex1 + x + x²/2 + x³/6 + o(x³)
sin xx − x³/6 + o(x³)
cos x1 − x²/2 + x⁴/24 + o(x⁴)
ln(1 + x)x − x²/2 + x³/3 + o(x³)

arctan xx − x³/3 + o(x³)
arcsin xx + x³/6 + o(x³)
1/(1 − x)1 + x + x² + x³ + o(x³)

展开到几阶？ 不要问「能不能替换」，问：分母是几阶，分子就展开到几阶。若展开后最低阶项仍被抵消，就再升一阶，直到抵消不掉。

2.4　洛必达法则陷阱

三个前提，缺一不可：

① 是 0/0 或 ∞/∞ 型
② 在去心邻域内 f, g 可导，且 g′(x) ≠ 0
③ lim f′/g′ 存在（或为 ∞）

三种失效情形：
① 求导后震荡：limx→∞ (x + sin x)/x = 1，但求导得 (1 + cos x)/1 不存在。此时洛必达失效，不能反推原极限不存在。
② 循环：ex sin x 类，反复求导回到自身。
③ 不是未定式却硬用：非未定式直接代入即可，用了反而错。

实操判断：求导一次后如果式子变复杂了，说明方向错了，立刻换泰勒。

2.5　夹逼准则

若 yn ≤ xn ≤ zn 且 lim yn = lim zn = a，则 lim xn = a。

什么时候用：n 项和，且分母不同次、无法凑成黎曼和时。思路是把每一项都换成最大项和最小项：

n · (最小项) ≤ 原式 ≤ n · (最大项)

若两端极限相等，中间就被夹住。

与定积分定义的分工：能凑成 (1/n)Σ f(i/n) 的形式就用定积分定义（答案精确）；凑不成就用夹逼（只求极限值）。
2.6　两个重要极限与 1∞ 型速解必背

limx→0 sin xx = 1　　　limx→∞ (1 + 1/x)x = e

变形：limx→0 (1 + x)1/x = e　，　limx→0 ln(1+x)x = 1

1∞ 型标准解法（设 u → 1, v → ∞）：

lim uv = elim v ln u = elim v(u−1)

最后一步用了 ln u ~ u − 1（因 u → 1，令 u = 1 + t 即得）。直接算 lim v(u−1) 是最快路径，比先取对数再洛必达省一半时间。

2.7　定积分定义（黎曼和）数竞

limn→∞ 1n n∑i=1 f(in) = ∫01 f(x) dx

识别特征（三个同时满足）：

① 求和号外有 1/n 或 1/n² 之类的因子
② 求和项是 i/n 的函数
③ 项数随 n 变化（n 项）

CMC 高频：这类题在数竞里出现频率远高于考研。看到「n 项和 + 极限」，第一反应就该是「能不能凑成黎曼和」。

例：limn→∞ 1n(√(1n) + √(2n) + ⋯ + √(nn)) = ∫01 √x dx = 23

2.8　斯托尔兹定理（数列版洛必达）数竞

若 yn 单调递增且趋于 +∞，且

lim xn+1 − xnyn+1 − yn = a　⇒　lim xnyn = a

用于数列的 ∞/∞ 型。数竞偶尔考，出现时通常是「n 项和 / n」这类结构。

CMC 中它不是必考项，但知道它能在一两道偏题上省时间。

三数列极限专题

3.1　单调有界准则必背

单调递增 + 有上界 ⇒ 收敛
单调递减 + 有下界 ⇒ 收敛

注意它只保证存在，不给值。值要靠「两边取极限解方程」求出（见 3.2）。

陷阱：有界但不单调（如 (−1)n），准则不适用，此时用夹逼或直接判断发散。
3.2　递推数列四步法必背

形如 an+1 = f(an)，标准流程固定四步：

步骤做什么常用手段
① 证有界证明 an 落在某区间数学归纳法
② 证单调判断递增或递减作差 an+1 − an 或作商
③ 求值设 lim an = A，两边取极限得 A = f(A)
④ 取舍解方程，排除多余根用单调性 / 界的范围筛掉
最常见的失分：跳过第 ①② 步直接解方程。CMC 解答题里，存在性证明本身占一半分数，只写「设极限为 A，A = f(A)」通常拿不到几分。

例：a1 = 1, an+1 = √(2 + an)。归纳可证 an < 2 且递增，故收敛；设极限 A，得 A² = 2 + A，即 A = 2（舍去 −1）。

3.3　压缩映射（进阶工具）

若存在 0 < k < 1 使 |f(x) − f(y)| ≤ k|x − y|，则递推数列必收敛。

它能一步跳过「证有界 + 证单调」，直接得到收敛性。判断条件通常是 |f′(x)| ≤ k < 1。

数竞里出现频率不高，但遇到递推式较复杂、单调性不好判断时，这是救命工具。

四连续性

4.1　连续的定义

f 在 x0 连续 ⟺ limx→x0 f(x) = f(x0)

三个条件：有定义、极限存在、极限等于函数值。缺一即间断。

4.2　间断点分类必背
大类小类特征
第一类
左右极限都存在		可去间断点左右极限相等，但不等于函数值（或无定义）
跳跃间断点左右极限存在但不相等
第二类
至少一个不存在		无穷间断点至少一侧极限为 ∞
振荡间断点如 sin(1/x) 在 x=0

找间断点的顺序：先找「可疑点」——分母零点、分段点、对数与根号的边界，再逐个求左右极限判断类型。

陷阱：分母零点不一定是间断点（可能约分后连续）。必须约分之后再判断，否则会把可去间断点误判成无穷间断点。
4.3　闭区间连续函数四大定理必背

前提都是：f 在闭区间 [a, b] 上连续。

定理内容
有界性f 在 [a,b] 上有界
最值定理f 在 [a,b] 上必取到最大值与最小值
介值定理介于最小最大值之间的任何数都能取到
零点定理若 f(a)·f(b) < 0，则存在 ξ ∈ (a,b) 使 f(ξ) = 0
零点定理是证明题的地基。后面中值定理那一章里，「构造辅助函数 + 用零点定理」是最常见的证明套路。这一条没吃透，中值定理就无从下手。

五CMC 特色题型

5.1　含参数反求 a、b数竞

已知 limx→0 f(x) = c（有限值），求参数。核心是一句话：

分母趋于 0 而极限存在 ⇒ 分子也必须趋于 0。

否则极限会是 ∞。由此得第一个方程；解出部分参数后，再用泰勒/洛必达确定剩余参数，使极限恰好等于给定值。

例：已知 limx→0 (sin x − ax)/x³ = b，求 a, b。

分子展开：sin x − ax = (1−a)x − x³/6 + o(x³)。若 1−a ≠ 0，极限为 ∞，故 a = 1；此时极限 = −1/6，即 b = −1/6。

5.2　求 α 使极限为非零常数数竞

形如：求 α 使 limx→0 f(x)/xα = c ≠ 0。

解法固定：把 f(x) 泰勒展开，找到最低阶非零项，它的阶数就是 α，系数就是 c。

这与 1.5 的「k 阶无穷小」定义完全对应——本质是在问「f 是 x 的几阶无穷小」。

这类题是数竞填空的高频款，特点是不需要复杂技巧，只需要展开不手抖。展开表背熟，这类题就是送分。
5.3　变限积分 + 洛必达数竞

核心公式：ddx ∫aφ(x) f(t) dt = f(φ(x)) φ′(x)

陷阱：上下限都含 x 时必须拆成两个积分再求导，别漏了负号那一项。被积函数里含 x 时，要先想办法把 x 提到积分号外或做变量替换，不能直接求导。

常见组合：lim ∫0x f(t)dtxn 型，直接洛必达 n 次，或用一次洛必达后用等价替换。

5.4　渐近线

三种，按顺序找：

类型求法
垂直渐近线找 x0 使 limx→x0 f(x) = ∞（通常是分母零点）
水平渐近线limx→∞ f(x) = b
斜渐近线k = limx→∞ f(x)/x，b = limx→∞ [f(x) − kx]（k ≠ 0 且有限）
陷阱：同一侧不可能同时有水平渐近线和斜渐近线。求斜渐近线时 x → +∞ 和 x → −∞ 要分别讨论，可能得到两条不同的斜渐近线（如 y = √(x²+1)）。

八条高频失分点陷阱

① 加减中滥用等价替换。只在乘除因子上换，加减必须泰勒。
② 洛必达用于非未定式。做题前先判断类型，这是第一步。
③ 洛必达求导后震荡就判定极限不存在。失效 ≠ 不存在，换方法再试。
④ 拆极限时没检查各自是否存在。四则运算的前提是都存在。
⑤ 忽略左右极限。见到 e1/x、arctan(1/x)、|x| 立刻分左右。
⑥ 把无限个无穷小之和当无穷小。「有限个」是硬条件。
⑦ 递推数列只求值不证存在。存在性占一半分数，别省。
⑧ 定积分定义与夹逼混淆。能凑黎曼和就用定积分，凑不上才夹逼。
