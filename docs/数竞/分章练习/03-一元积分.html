03 · 一元函数积分学

占分最重的一块 · 约 22 分

填空真题 5 道 解答题 高频 建议 3 天
这是整份大纲里分值最高的板块（约 22 分）。但它有个特点：填空只考「算」，解答题才考「证」。积分不等式的证明是 CMC 的常客，而且年年难度不低——第八届一道、第四届一道，都是压轴级别的。

一、填空题清单（计算类）

A. 定积分计算 · 分部与换元

出处题目要点
16届 第1题∫₀¹ ln(1+x²) dx
11届 第3题∫ (1+sin x)ex/(1+cos x)² dx
10届 第3题∫ ln(x+√(1+x²))/(1+x²) dx
16届那题的标准解法：直接分部，u=ln(1+x²)，dv=dx，得到 x ln(1+x²) − ∫2x²/(1+x²)dx，后面把 2x²/(1+x²) 拆成 2 − 2/(1+x²) 就好算了。答案是 ln2 − 2 + π/2。
10届那题的信号：看到 ln(x+√(1+x²)) 立刻想到它的导数是 1/√(1+x²)，所以配 1/(1+x²) 时应该令 x=tan t，把 dx/(1+x²) 变成 dt。

B. 不定积分技巧

出处题目要点
9届 第5题∫ ex(1−sin x)/(1−sin x)² dx
这类题的通法：分子分母都含 (1−sin x) 的幂，本质是「凑 d[u/v]」。思路是从结果倒推——想找 F 使 F′ = ex(1−sin x)/(1−sin x)²，而 ex 提示 F = ex·g(x)，代进去解 g。

C. 变限积分 · 积分方程

出处题目要点
9届 第1题f(x)cos x + 2∫₀xf(t)sin t dt = x+1，求 f(x)
13届 第3题f 连续且 f(0)≠0，求含 ∫₀xf(t)dt 的极限
积分方程的标准动作：两边求导。9届那题先移项得 2∫₀xf(t)sin t dt = x+1−f(x)cos x，两边对 x 求导就变成微分方程了。注意：求导前先代 x=0 得初始条件。

二、解答题清单（证明类）

题型识别特征与应对
积分不等式证明
最高频		「证明 ∫f ≥ ∫g」或「证明 ∫f · ∫(1/f) ≥ 1」——用单调性、柯西不等式、或构造变限积分函数
积分中值定理「证明存在 ξ 使 ∫f = f(ξ)(b−a)」——第八届第 5 题就是这个
变限积分函数性质证 F(x)=∫₀xf 的单调性、凹凸性、零点个数
积分与极限结合n 项和 → 定积分定义（黎曼和）
积分不等式的三个常用武器：
① 构造变限积分：令 F(x)=∫₀x(f−g)，证 F≥0——最通用
② 柯西—施瓦茨：(∫fg)² ≤ ∫f²·∫g²——看到「乘积的积分」就想到它
③ 单调性：把常数 b 换成变量 x，变成函数再求导比较

三、必背公式

变限积分求导（这是本章最重要的一个公式）：

d/dx ∫aφ(x) f(t)dt = f(φ(x))·φ′(x)

上下限都含 x 时：d/dx ∫ψ(x)φ(x) f = f(φ)φ′ − f(ψ)ψ′

华里士公式（点火公式）：∫₀π/2sinnx dx = ∫₀π/2cosnx dx，n 为偶数时 = (n−1)!!/n!! · π/2，奇数时 = (n−1)!!/n!!

对称区间：∫−aaf = 0（f 为奇函数），= 2∫₀af（f 为偶函数）

周期：∫aa+Tf = ∫₀Tf

四、练习顺序

三天，先算后证：
第 1 天（计算）：16届1（分部）→ 10届3（三角换元）→ 9届5（凑微分）→ 11届3（分部 + 凑）
第 2 天（变限积分）：9届1（积分方程）→ 13届3（变限极限）→ 再练 3 道「求 F(x)=∫₀xf 的导数」的基础题
第 3 天（证明）：先做 2 道「构造变限积分证不等式」，再碰柯西—施瓦茨的题
一个容易忽略的点：积分不等式证明里，「把常数换成变量」这个技巧（令 F(x)=∫₀x… 或把 b 看成 x）是通用钥匙。看到不等式两端一个是常数一个是积分，先想这招。
