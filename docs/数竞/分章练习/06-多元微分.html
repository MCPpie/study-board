06 · 多元函数微分学

近三年年年考，题型高度固定 · 约 8 分

填空真题 8 道 题型 4 类 建议 1 天
信号：第十五届第 2 题、第十六届第 3 题、第十七届第 4 题，连续三年都考这一章。位置在变（第 2、第 3、第 4 题），题型在「复合二阶偏导」和「隐函数求偏导」之间轮换。这章只要把「链式法则画树」练成肌肉记忆，6 分基本白送。

出处题目要点

8届 第5题曲面 z=… 平行于平面 2x+2y−z=0 的切平面

二、核心方法：链式法则画树

以 15届第2题 z=f(x²−y², xy) 为例：

设 u = x²−y²，v = xy，则 z = f(u,v)。

一阶：

zx = f₁·ux + f₂·vx = f₁·2x + f₂·y

二阶：对 zx 再对 y 求导。注意 f₁, f₂ 本身也是 u,v 的函数，要对它们再用一次链式法则：

(f₁)y = f₁₁·uy + f₁₂·vy = f₁₁·(−2y) + f₁₂·x

(f₂)y = f₂₁·uy + f₂₂·vy = f₂₁·(−2y) + f₂₂·x

这一步是绝大多数人出错的地方——忘了对 f₁, f₂ 二次展开。

记住一句话：f₁ 也是 x, y 的复合函数，求导时它不能当常数。一阶求导时把 f₁, f₂ 看成符号；二阶求导时它们必须再展开一次。

三、隐函数求偏导

方法一（推荐）：两边直接求导。以 17届第4题 xz = f(2x−y, xyz) 为例，两边对 x 求偏导（y 视为常数，z 是 x 的函数）：

z + x·zx = f₁·2 + f₂·(yz + xy·zx)

整理出 zx，再代入 x=1, y=0, z=f(2,0)=3, f₁(2,0)=5。

答案是 7。

方法二（公式法）：令 F(x,y,z) = xz − f(2x−y, xyz)，则 zx = −Fx/Fz。公式法不容易漏项，但计算量大；两边求导更直观。考场上建议用两边求导。

四、几何应用

曲面 F(x,y,z)=0 在点 P 的法向量：n = (Fx, Fy, Fz) 在 P 处取值

切平面：Fx(x−x₀) + Fy(y−y₀) + Fz(z−z₀) = 0

「切平面平行于已知平面」的做法：令法向量与已知平面法向量成比例，解出切点坐标，再写切平面方程。

「两曲面相切」的做法：在切点处两曲面的法向量平行，即梯度成比例。

五、练习顺序

一天，按这个顺序：
① 17届4（隐函数，最新）→ ② 15届2（复合二阶，最典型）
③ 16届3（复合二阶，含指数，稍难）→ ④ 13届2（隐函数，求 zx+zy）
⑤ 8届5（切平面）→ ⑥ 11届5（相切条件）
⑦ 9届3（抽象 f(u,v)，练符号运算）
自查标准：能不能在 8 分钟内、不看书、把 z=f(x²−y²,xy) 的 ∂²z/∂x∂y 完整写出来（包括 f₁₁, f₁₂, f₂₂ 所有项）？做不到就再练两道同类题。这题会了，16届和17届的同类题都是换皮。
