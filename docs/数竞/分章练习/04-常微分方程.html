04 · 常微分方程

占分不高，但规律极强 · 约 6 分

真题 6 道 核心 换元 建议 1 天
这一章有个全表最干净的规律：近三年解答题连续考「一阶方程 + 换元」。不是标准型，全是需要你先换个变量、化成标准型才能解的。三年三道，套路完全一致。这是投入产出比最高的一章——一天就能吃透。

一、近三年解答题：三道同型题

出处原方程换元方向
17届 第7题y′x ln x sin y + (1−x cos y)cos y = 0令 z=cos y → Bernoulli，再令 u=z−1 → 线性
16届 第6题(x³−y²)dx + (x²y+xy)dy = 0令 u=y² → 一阶线性
15届 第6题(x²+y²+3)dy/dx = 2x(2y−x²/y)令 u=x², v=y² → 齐次型
三题的共同点：都不是「可分离 / 齐次 / 线性 / Bernoulli」四种标准型的原样，都需要先做一个形如 z = y² 或 z = cos y 的代换，把方程拍平成标准型。

换元的信号：看到 y² 和 y dy 同时出现 → 令 u=y²；看到 sin y 和 cos y 混着 y′ → 令 z=cos y。
一个值得注意的复用：17届第 7 题和 14届填空第 4 题几乎是同一道题——14届是 y′ln x sin y + (1−cos y)cos y = 0，17届在每项上多乘了个 x。这说明命题人会拿旧题做加强版。你刷旧题的时候，不妨想想「如果每项乘个 x 会怎样」。

二、填空题清单

出处题目要点
14届 第4题y′ln x sin y + (1−cos y)cos y = 0 的通解（17届7的母题）
11届 第2题一阶方程求解
8届 第3题z=f(xy²)，已知 ∂z/∂x 的表达式，反求 f(x)——本质是解微分方程
8届那题容易被误判：它看起来是多元微分题，但求出 f′ 之后要积分回去，实际考的是「由导数反求原函数」。这类「跨章」题在 CMC 里不少，别只按单一章节归类。

三、四种标准型与解法

类型标准形式解法
可分离变量y′ = f(x)g(y)分离：dy/g(y) = f(x)dx，两边积分
齐次型y′ = φ(y/x)令 u=y/x，化为可分离
一阶线性y′ + P(x)y = Q(x)公式：y = e−∫P(∫Q e∫Pdx + C)
Bernoulliy′ + P(x)y = Q(x)yn令 z=y1−n，化为一阶线性
最容易记混的地方：Bernoulli 的换元是 z = y1−n，不是 z = yn。17届那题先换 z=cos y 得到 z′ − z/(x ln x) = −z²/ln x，这是 n=2 的 Bernoulli，所以再令 u = z1−2 = z−1。两层换元，别在第二层搞错指数。

四、二阶常系数线性（可能考）

齐次 y″ + py′ + qy = 0：解特征方程 r² + pr + q = 0

判别式通解
两不等实根 r₁≠r₂y = C₁er₁x + C₂er₂x
重根 r₁=r₂=ry = (C₁ + C₂x)erx
共轭复根 α±βiy = eαx(C₁cos βx + C₂sin βx)

非齐次：特解形式按右端项设。eλxP(x) → 设 xkeλxQ(x)，k 是 λ 作为特征根的重数。

五、练习顺序

一天搞定，按这个顺序：
① 14届4（母题，先做填空版）→ ② 17届7（同题加强版，检验是否真懂）
③ 16届6（换元 u=y²）→ ④ 15届6（双换元）
⑤ 8届3（跨章题，练手感）
⑥ 如果还有时间，把二阶常系数的三种情形各练 2 道
做完自查：能不能在 5 分钟内判断「这题该换什么元」？如果做不到，说明你还在背题型而不是理解结构。判断方法：看方程里哪个变量的幂次不对——出现 y² 就想降次，出现三角函数就想用 cos 或 tan 换掉。
