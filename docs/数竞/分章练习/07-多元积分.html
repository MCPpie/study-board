一、近三年那三道题（优先刷）

出处题目核心技巧
17届 第5题∫L(x²+2xy)ds，L 为球面 x²+y²+z²=4 与平面 x+y+z=3 的交线轮换对称性
16届 第5题∮L(−y dx+x dy)/(4x²+y²)，L: x²+y²=9 逆时针格林公式 + 换路径
15届 第5题∬Σ(x+y+z)dS，Σ 为 y+z=5 被柱面 x²+y²=25 截得部分投影 + 对称性

17届第 5 题的完整思路（这道最值得吃透）

第一步：算出交线是圆，求周长。球心到平面 x+y+z=3 的距离 d = 3/√3 = √3，球半径 2，所以圆半径 √(4−3)=1，周长 2π。

第二步：拆成两部分。∫(x²+2xy)ds = ∫x²ds + 2∫xy ds

第三步：用轮换对称处理 ∫x²ds。在 L 上 x²+y²+z²=4 恒成立，且 x,y,z 地位对称：

∫x²ds = ∫y²ds = ∫z²ds = ⅓∫(x²+y²+z²)ds = ⅓·4·2π = 8π/3

第四步：用平方关系处理 ∫xy ds。由 x+y+z=3：

(x+y+z)² = x²+y²+z² + 2(xy+yz+zx) = 9
⇒ xy+yz+zx = (9−4)/2 = 5/2

再由轮换对称，∫xy ds = ∫yz ds = ∫zx ds = ⅓·(5/2)·2π = 5π/3。

结果：8π/3 + 2·5π/3 = 6π。

这道题的通用套路：遇到「球面与平面交线」上的第一类曲线积分，几乎一定是轮换对称 + 平方关系。记住两个抓手：x²+y²+z²=R² 给出平方和，x+y+z=c 给出一次和，两者一联立就能把交叉项全部求出来。

16届第 5 题的思路（格林公式的标准用法）

被积函数在原点处有奇点，不能直接用格林。换一条路径：令 L₁: 4x²+y²=4（椭圆），在 L 与 L₁ 围成的环形区域上用格林公式，得到 ∮L+L₁ = 0，所以 ∮L = −∮L₁。

再对 L₁ 用格林，得 ¼·2·σ(D) = ½·2π = π。答案是 π。

关键：看到 (−y dx + x dy)/(x²+y²) 这类形式，先检查 Qx − Py 是否为 0。为 0 说明「积分与路径无关」，可以直接换一条好算的路径。这是这类题的题眼。

二、二重积分真题

出处题目要点考点
14届 第5题∬D sin(x+y)dxdy，D 为三角形区域对称性 / 三角公式
16届 第2题limr→0+ ∬D(ex²+y²−1)dxdy / r⁴，D: x²+y²≤r²极坐标 + 极限
12届 第4题由 ∫₀∞sin x/x dx = π/2 求含参二重积分换序
16届那题是个漂亮的小题：极坐标后变成 2π∫₀r(eρ²−1)ρdρ = π(er²−1−r²)，而 er²−1−r² ~ r⁴/2，所以答案是 π/2。它同时考了极坐标、变上限积分、泰勒展开三件事，是很好的综合练习。

三、三重积分与曲面积分（解答题）

出处题目要点方法
17届 第8题∭Ωdxdydz/√(y²+z²)，Ω 由 x=0, x=y, y=z, z=1, z=2 围成截面法（先二后一）
16届 第8题∬S(x²−x)dydz + (y²−y)dzdx + (z²−z)dxdy，S 为上半球面高斯公式 + 补面
15届 第7题圆锥面与椭球面相切，求所围体积空间几何 + 重积分
9届 第6题锥面 z²=x²+y² 与球面 z=√(4−x²−y²) 围成区域的三重积分柱坐标 / 球坐标
17届第 8 题为什么用截面法：被积函数只含 y,z，与 x 无关。所以固定 z 后，先对 x,y 积一层，再对 z 积。这就是「先二后一」。判断信号：被积函数缺某个变量，或者积分区域在某个方向是柱状。

四、四类积分的公式对照

类型记号主力工具
第一类曲线积分∫L f ds参数化 + 对称性（轮换、奇偶）
第二类曲线积分∫L P dx + Q dy格林公式；或判断与路径无关
第一类曲面积分∬Σ f dS投影 + dS = √(1+zx²+zy²)dxdy + 对称性
第二类曲面积分∬Σ P dydz + Q dzdx + R dxdy高斯公式（补面、注意方向）

格林：∮LP dx + Q dy = ∬D(Qx − Py)dxdy　　高斯：∬Σ = ∭Ω(Px+Qy+Rz)dV

最容易错的三件事：
① 方向。格林公式要求 L 正向（逆时针），高斯要求外法向。方向反了要加负号。
② 补面。用高斯时曲面必须封闭，不封闭要补一块，补的那块最后要减掉。
③ 奇点。被积函数在区域内无定义时不能直接用格林/高斯，要挖洞或换路径（16届第 5 题就是典型）。

五、练习顺序

两天，先啃信号题：
第 1 天（曲线曲面积分）：17届5（轮换对称）→ 16届5（格林 + 换路径）→ 15届5（投影 + 对称）
第 2 天（重积分）：16届2（极坐标 + 极限）→ 14届5（对称性）→ 17届8（截面法）→ 16届8（高斯 + 补面）
