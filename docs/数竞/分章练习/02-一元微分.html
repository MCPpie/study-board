02 · 一元函数微分学

填空考计算，解答题考证明 · 约 20 分

填空真题 5 道 题型 5 类 建议 2 天
先说最重要的一件事：中值定理不在这份清单里。十年填空题里几乎没有考过中值定理——它只出现在解答题和证明题。所以「按章节练填空」练不到它，而它恰恰是这章 20 分里的主要来源。这一章必须两条腿走：填空练计算，解答练证明。

一、填空题清单（计算类）

A. 高阶导数 · 莱布尼茨公式

出处题目要点
12届 第2题f(x)=(x+1)²enx，求 f(n)(1)
8届 第4题f(x)=exsin 2x，求 f(4)(0)
两个套路：
① 多项式 × 指数函数（12届）→ 用莱布尼茨，(x+1)² 只有三阶以内非零，展开只剩 3 项。
② 指数 × 三角（8届）→ 也可以莱布尼茨，但更快的是把 exsin 2x 写成 Im[e(1+2i)x]，四阶导数直接出来。

B. 高阶导数 · 有理函数拆分

出处题目要点
15届 第3题f(x)=1/(x²−3x+2)，求 f(n)(0)
解法：先拆成部分分式 1/(x²−3x+2) = 1/(x−2) − 1/(x−1)，再用 (1/(x−a))(n) = (−1)nn!/(x−a)n+1。看到分母能因式分解的有理函数求高阶导，一律先拆。

C. 隐函数求导 · 切线

出处题目要点
12届 第3题y=f(x) 由 arctan(xy) = ln(...) 确定，f(1)=1，求 (1,1) 处切线
解法：两边对 x 求导，把 y′ 解出来，代点 (1,1) 得斜率。注意隐函数求导时 y 是 x 的函数，每遇到 y 都要乘 y′。

D. 参数方程求导 · 切线

出处题目要点
10届 第2题曲线由参数方程确定，求 t=0 对应点处的切线
公式：dy/dx = y′(t)/x′(t)。别忘了先算出 t=0 对应的点坐标，切线方程需要点斜式。

E. 导数应用 · 单调性与最值

出处题目要点
16届 第7题（解答）f(x)=1/ln(1+x) − 1/x（0<x≤1），求 k 使其在 x=0 连续，并求最大最小值
这是一道标准题：先求 limx→0+f(x) 定 k（得 1/2），再求导判单调，最后取端点与驻点。它的价值在于示范「连续 + 单调 + 最值」的完整流程，建议整题抄一遍。

二、解答题清单（证明类 · 这才是重点）

这部分我无法给你精确的届次题号——解答题的题干和答案在 PDF 里混排，公式错位严重，逐题确认会出错。以下是这章在解答题里的题型，你翻自己 PDF 时按这些形态去找。
题型识别特征
中值定理证明「证明存在 ξ∈(a,b) 使 …」——罗尔 / 拉格朗日 / 柯西 / 泰勒
构造辅助函数要证的式子里有 f′ 和 f 混在一起，需要造 F(x)
不等式证明「证明当 x>0 时 …」——用单调性或拉格朗日
零点个数「证明方程 … 有且仅有 n 个根」——零点定理 + 单调性
中值定理的入门顺序（别跳）：
① 罗尔定理 → ② 拉格朗日 → ③ 柯西 → ④ 泰勒
每学完一个，立刻做 2 道「直接套用」的题，再碰「需要构造辅助函数」的题。辅助函数构造是分水岭，前面三步只是热身。

三、必背

莱布尼茨公式：(uv)(n) = Σk=0n C(n,k) u(n−k) v(k)

常见高阶导：

(eax)(n)aneax
(sin x)(n)sin(x + nπ/2)
(cos x)(n)cos(x + nπ/2)
(ln x)(n)(−1)n−1(n−1)!/xn
(1/(x−a))(n)(−1)nn!/(x−a)n+1

参数方程：dy/dx = y′(t)/x′(t)；隐函数：两边求导，把 y′ 当未知数解出来。

四、练习顺序

先计算后证明，两天：
第 1 天（计算）：15届3（有理拆分）→ 12届2（莱布尼茨）→ 8届4（指数×三角）→ 12届3（隐函数切线）→ 10届2（参数方程）
第 2 天（证明）：先读罗尔定理 + 做 2 道直接套用的题 → 拉格朗日 2 道 → 才开始碰构造辅助函数的题
如果第 2 天卡住了，正常。中值定理的辅助函数构造是整本高数里最难自学的部分，卡住不代表你笨。卡的时候把「要证的结论」倒着推——从结论反推 F(x) 应该长什么样，比正着试有效得多。
