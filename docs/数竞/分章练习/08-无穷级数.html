08 · 无穷级数

填空 + 解答都有 · 约 12 分

真题 4 道 题型 3 类 建议 1 天
这章的特点是「考得不多，但每次都考得不简单」。第十七届的判敛题（Σ sin²x·sin²2x⋯sin²(2nx)）是典型的 CMC 风格——不是套比值判别法，而是要你先求被乘函数的最大值，再做几何级数估计。这类题考研很少见。

一、真题清单

A. 幂级数收敛域

出处题目要点
15届 第4题Σn=1∞ (−1)n−1x2n/(n(2n−1)) 的收敛域
解法：用比值法求半径 R，得 |x|<1；再分别检查端点 x=±1。代入后是交错级数，用莱布尼茨判别法确认收敛。答案是 [−1, 1]，注意是闭区间。

B. 幂级数求和函数

出处题目要点
14届 第3题先求 Σ n²xn 的和函数，再算 lim(1+1/n)n 型极限
求和函数的三板斧：
① 逐项求导——系数里有 n、n² 时用
② 逐项积分——系数里有 1/n 时用
③ 先积后导 / 先导后积——凑成已知级数（Σxn = 1/(1−x)）

C. 数项级数判敛（CMC 特色）

出处题目要点
17届 第9题（解答）Σ an，其中 an = sin²x·sin²2x⋯sin²(2nx)，x∈(−∞,+∞)，判断收敛性

这题的思路（值得完整看一遍）：

第一步：令 f(x)=sin²x·sin 2x，求它的最大值。求导得 f′(x) = 2sin²x(3−4sin²x)，在 (0,π) 内驻点为 π/3, 2π/3。

第二步：算出 |f| ≤ 3√3/8。

第三步：把 an 拆成可估计的形式。

an3/2 = |sin x|·|f(x)f(2x)⋯f(2n−1x)|·|sin²2nx| ≤ (3√3/8)n

第四步：右边是公比小于 1 的几何级数，收敛，故 Σan3/2 收敛。再由比较判别法得 Σan 收敛。

这题的关键洞察：不是直接对 an 判敛，而是先把连乘拆成「每个因子都小于某个常数」，凑成几何级数。看到连乘形式的级数，第一反应就该是「求单个因子的上界」。

D. 傅里叶级数

出处题目要点
8届 第6题（解答）f(x) = f(x+2) = f(x+√3)，用傅里叶级数理论证明 f(x) 为常数
这题很巧：两个周期 2 和 √3 不可公度，说明 f 的周期可以任意小，即 f 是常数。用傅里叶的语言说：所有傅里叶系数都为 0。这是「周期理论」的经典应用，值得看一眼原解答。

二、判敛方法速查

方法适用判据
比值法含 n!、an、nnlim an+1/an = ρ
根值法含 n 次方lim n√an = ρ
比较法与 1/np 比p>1 收敛，p≤1 发散
莱布尼茨交错级数an 单调递减且趋于 0
绝对收敛含 sin、cos、(−1)n先判 Σ|an|
易错：比值法失效（ρ=1）时不能下结论，要换方法。比如 Σ1/n 和 Σ1/n² 的比值极限都是 1，但一个发散一个收敛。

三、练习顺序

一天：
① 15届4（收敛域，最基础也最常考）
② 14届3（求和函数，练三板斧）
③ 17届9（CMC 特色判敛，重点看思路）
④ 8届6（傅里叶，看一眼原解答就够，不用深挖）
取舍建议：如果时间只剩一天，优先保「收敛域」和「求和函数」——这两个是填空题的常客，套路固定。17届那种连乘判敛属于「见了就赚，不见不亏」，不必专门花时间。傅里叶级数同理，十年只出现过一次（第八届），优先级最低。
