一、真题清单

出处题目要点
17届 第2题求过原点与点 (6,−3,2)、且与平面 4x−y+2z−8=0 垂直的平面方程
16届 第4题直线 (x−1)/1 = y/1 = (z−1)/(−1) 与平面 π: x−y+2z−1=0，求交点与投影

二、17届那题的完整解法

第一步：设平面。过原点 → 常数项 D=0，所以设 Ax+By+Cz=0，法向量 n=(A,B,C)。

第二步：用过点定一个方程。代入 (6,−3,2)：

6A − 3B + 2C = 0　…①

第三步：用垂直定第二个方程。所求平面 ⊥ 已知平面 4x−y+2z−8=0，即两法向量垂直：

(A,B,C)·(4,−1,2) = 0　⇒　4A − B + 2C = 0　…②

第四步：解比例。①−② 得 2A − 2B = 0 ⇒ A=B。代回②：4A − A + 2C = 0 ⇒ C = −3A/2。

取 A=B=2, C=−3，得 2x + 2y − 3z = 0。

关键洞察：两个条件 → 两个方程 → 三个未知数，只能定出比例。所以最后要「取一组整数」，不用纠结具体值。

三、必背公式（就这六条）

对象公式
平面 · 点法式A(x−x₀) + B(y−y₀) + C(z−z₀) = 0
平面 · 一般式Ax + By + Cz + D = 0，法向量 n=(A,B,C)
两平面垂直A₁A₂ + B₁B₂ + C₁C₂ = 0
两平面平行A₁/A₂ = B₁/B₂ = C₁/C₂
直线 · 对称式(x−x₀)/l = (y−y₀)/m = (z−z₀)/n，方向向量 s=(l,m,n)
点到平面距离d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)
最容易混的两组：
① 平面的法向量是 (A,B,C)（方程系数），直线的方向向量是 (l,m,n)（分母）。别搞反。
② 「直线 ⊥ 平面」是 s ∥ n；「直线 ∥ 平面」是 s ⊥ n。垂直和平行的对应关系是反的。

四、16届那题的思路（直线与平面）

求交点：把直线写成参数式 x=1+t, y=t, z=1−t，代入平面方程解出 t，回代得交点。

求投影直线：先过该直线作一个垂直于已知平面的平面（用直线方向向量 × 平面法向量得到新法向量），再与已知平面联立，即得投影直线。

这类题的固定套路：直线 ⊥ 平面 → 平面束 / 参数代入。「投影」两个字出现时，一定是「作垂直平面 + 联立」。
