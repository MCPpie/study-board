01 · 函数、极限、连续

十年填空里出现最多的板块 · 约 13 分

真题 16 道 题型 7 类 建议 2 天
为什么先练这章：十年填空约 47 道题里，极限独占 13 道，是频率最高的一块。而且它不只是独立考点——导数定义、定积分定义、级数判敛，本质全是极限。这章练透，后面几章都会顺。

一、十年真题清单

按「题型」分组排列，不是按届次。每组内部从新到旧。

A. 泰勒定阶 / 求参数 最高频

出处题目要点
17届 第1题f(x)=x−ln(1+x)−½x sin x，g(x)=ax³，已知 limx→0 f/g = 1，求 a
9届 第4题f 二阶连续可导，f(0)=f′(0)=0，f″(0)=6，求 limx→0 f(sin²x)/x⁴
8届 第2题f(1)=0，f′(1) 存在，求含 f(sin²x+cos x) 的极限
解法：把分子展开到与分母同阶。17届那题分母是 x³，就把 ln(1+x) 展开到 x³、sin x 展开到 x³，相减后取最低阶非零项，系数比即为答案。答案是 −1/3。

B. 等价无穷小组合

出处题目要点
12届 第1题limx→0 (x−sin x)ex² / (∛(1−x³)−1)
11届 第1题含 ln(esin x+∛(1−cos x)) 与 arctan(∜(1−cos x)) 的复合结构
10届 第4题limx→0 (1−cos x)/x² 型
陷阱：12届那题分子是 x−sin x，如果分别替换成 x−x=0 就错了。必须用三阶等价 x−sin x ~ x³/6。这就是「加减不能换」的经典考法。

C. 洛必达 / 根式有理化

出处题目要点
15届 第1题limx→3[√(x³+9) − 3 − √(x³−23)]
14届 第1题含 cos 的 0/0 型
13届 第1题limx→+∞[√(x²+x+1) − x − ln(ex+x)]
解法：15届那题先通分合并根式，再洛必达；13届那题是 ∞−∞，先提 x 再逐项处理。判断信号：看到根式先想有理化，看到 ∞−∞ 先想提公因子。

D. 变限积分型极限

出处题目要点
17届 第3题limx→0 ∫₀sin²xln(1+t)dt / [(∛(1+x³)−1)·sin x]
13届 第3题f 连续且 f(0)≠0，求含 ∫₀xf(t)dt 的极限
解法：洛必达一次，上限函数求导得 f(φ(x))φ′(x)，然后剩下的用等价无穷小。17届答案 3/2。

E. 1∞ 型

出处题目要点
8届 第1题f 在 a 处可导且 f(a)≠0，求 limn→∞[f(a+1/n)/f(a)]n
速解：lim uv = elim v(u−1)。这题 u−1 = [f(a+1/n)−f(a)]/f(a)，乘以 n 得 f′(a)/f(a)，所以答案是 ef′(a)/f(a)。不要先取对数再洛必达，太慢。

F. 数列极限

出处题目要点
10届 第1题limn→∞[(n+1)α − nα]，α∈(0,1)
解法：提出 nα，得 nα[(1+1/n)α−1] ≈ nα·α/n = αnα−1。因 α<1，极限为 0。

G. 导数定义伪装成极限

出处题目要点
9届 第2题含反三角与根式的极限（凑导数定义）

二、解法地图

第一步永远是判断类型。七种未定式对应七套工具：

类型转化主力工具
0/0直接处理等价 → 泰勒 → 洛必达
∞/∞直接处理抓大头 / 洛必达
0·∞写成 0/(1/∞)转成上面两种
∞−∞通分 / 有理化 / 提公因子转成上面两种
1∞elim v(u−1)直接算指数
00 / ∞0ev ln u指数化

口诀：乘除换等价，加减上泰勒；阶数看分母，抵消再升阶。

「阶数看分母」怎么用：分母是 x³，分子就展开到 x³；展开后如果最低阶项被抵消，就再升一阶。不要背「能不能替换」，只判断阶数。

四、练习顺序

按这个顺序刷，一天半能走完：
① 17届1（泰勒定阶，最新最典型）→ ② 9届4（同类，换皮）
③ 12届1（等价无穷小的坑）→ ④ 10届4（简单的等价）
⑤ 17届3（变限积分 + 极限）→ ⑥ 13届3（同类）
⑦ 15届1（根式 + 洛必达）→ ⑧ 13届1（∞−∞）
⑨ 8届1（1∞ 速解）→ ⑩ 10届1（数列）
卡住的时候：先回 《CMC 极限知识点手册》 查对应章节，别直接看答案。每道题做完记下「我卡在哪一步」——是没想到方法，还是展开阶数错了，还是算错。这三种问题的解法完全不同。
