卷一 基础卷 90 分钟 / 100 分

一、选择题 每题 5 分，共 20 分

1.一定量理想气体温度保持不变，体积被压缩为原来的 1/2，则分子的平均自由程 λ 变为原来的：
A2 倍
B1/2
C1/4
D不变
2.刚性双原子理想气体在等压过程中吸收的热量，有百分之多少用于对外做功：
A2/7 ≈ 28.6%
B3/5 = 60%
C2/5 = 40%
D5/7 ≈ 71.4%
3.关于熵，下列说法正确的是：
A熵是过程量，与路径有关
B任何过程中系统的熵都不会减少
C可逆绝热过程的熵变为零
D系统吸热则熵一定增加
4.麦克斯韦速率分布下，最概然速率 vp、平均速率 v̄、方均根速率 √(v̄²) 的大小关系是：
Avp < v̄ < √(v̄²)
Bvp > v̄ > √(v̄²)
Cv̄ < vp < √(v̄²)
D三者相等
展开选择题答案
1. B　λ = 1/(√2·πd²n)，n = N/V。V 减半 → n 加倍 → λ 减半。
2. A　W = νRΔT，Q = νCpΔT = (7/2)νRΔT，W/Q = 2/7 ≈ 28.6%。剩下 5/7 都变成内能了。
3. C　A 错：熵是状态函数。B 错：只有孤立系统熵不减，系统放热时熵会减小。D 错：还要看是否可逆、是否对外做功，等温膨胀吸热同时熵增，但绝热压缩温度升高而熵不变。
4. A　vp = √(2RT/M)，v̄ = √(8RT/πM)，√(v̄²) = √(3RT/M)。系数 2 < 2.55 < 3。

二、填空题 每空 3 分，共 18 分

5.1 mol 单原子理想气体在 T = 300 K 下等温膨胀到体积为原来的 2 倍，则 ΔU = ?，Q = ?，W = ?。
6.热力学第二定律的统计意义：孤立系统总是从包含微观状态数?的宏观态，自发地向包含微观状态数?的宏观态进行。
7.一卡诺热机工作在 400 K 与 300 K 两热源之间，其效率 η = ?。
展开填空题答案
5.　ΔU = 0（等温，理想气体内能只与 T 有关）；
W = νRT ln(V₂/V₁) = 8.31 × 300 × 0.693 = 1.73×10³ J Q = W = 1.73×10³ J（吸热，全部转化为对外做功） 6.　少 → 多。这就是「熵增」的微观解释：系统自发走向更无序、更可能出现的状态。
7.　η = 1 − T₂/T₁ = 1 − 300/400 = 25%。

三、计算与简答题 共 62 分

8.（12 分）容器内有 2 mol 氧气（视为刚性双原子分子），温度 300 K。求： (1) 气体的内能；(2) 分子的方均根速率；(3) 分子的平均平动动能。
（M = 32 g/mol）
9.（12 分）1 mol 刚性双原子理想气体，初温 T₁ = 300 K，经等压膨胀到体积变为原来的 2 倍。求该过程的 W、ΔU、Q。
10.（12 分）1 mol 刚性双原子理想气体经历如下循环：
① 等容升温，压强变为原来 2 倍 → ② 等温膨胀，体积变为原来 2 倍 → ③ 等压压缩回到初态。
求循环效率 η。
11.（12 分）1 kg 水从 20 ℃ 加热到 100 ℃（c = 4.18×10³ J/(kg·K)）。求水的熵变。
12.（14 分）简述：为什么温度是分子平均平动动能的量度，而不是平均总动能的量度？
展开计算题答案与解析
8. 双原子 i = 5
(1) U = (i/2)νRT = 2.5 × 2 × 8.31 × 300 = 1.25×10⁴ J (2) √(v̄²) = √(3RT/M) = √(3×8.31×300/0.032) = ≈ 483 m/s (3) ε̄k = (3/2)kT = 1.5 × 1.38×10⁻²³ × 300 = 6.21×10⁻²¹ J 易错：内能用 i=5，但平均平动动能只用 3 个平动自由度，两者别混
展开计算题答案与解析
9. 等压 → V ∝ T，V 变 2 倍则 T₂ = 2T₁ = 600 K，ΔT = 300 K
W = pΔV = νRΔT = 1 × 8.31 × 300 = 2.49×10³ J ΔU = (5/2)νRΔT = 2.5 × 8.31 × 300 = 6.23×10³ J Q = ΔU + W = 8.72×10³ J 也可直接用 Q = νCpΔT = (7/2)RΔT 验算，结果一致
展开计算题答案与解析
10. 设初态 (p₁, V₁, T₁)。1→2 等容到 (2p₁, V₁, 2T₁)；2→3 等温到 (p₁, 2V₁, 2T₁)；3→1 等压回到初态。
Q₁₂（等容，吸热）= (5/2)R(T₂−T₁) = 2.5 × 8.31 × 300 = 6.23×10³ J Q₂₃（等温，吸热）= W = RT₂ln2 = 8.31 × 600 × 0.693 = 3.46×10³ J Q₃₁（等压，放热）= (7/2)R(T₁−2T₁) = −3.5 × 8.31 × 300 = −8.72×10³ J W净 = Q吸 − |Q放| = (6.23+3.46) − 8.72 = 0.97×10³ J η = W净/Q吸 = 0.97/(6.23+3.46) ≈ 10% 易错：分母只放「吸」的两项，放热的 8.72 不能进分母
展开计算题答案与解析
11. 加热可视为可逆过程，用 ΔS = mc·ln(T₂/T₁)
T₁ = 293 K，T₂ = 373 K ΔS = 1 × 4.18×10³ × ln(373/293) = 4180 × 0.2414 ΔS ≈ 1.01×10³ J/K（熵增，符合预期）
展开简答题答案与解析
12. 温度由分子平均平动动能定义：ε̄k = (3/2)kT，这里的 3 只算三个平动自由度。
转动自由度不参与温度的定义——因为温度是通过压强（分子对器壁的碰撞动量）来测量的，而碰撞只与平动有关。
所以双原子分子的平均总动能是 (5/2)kT，但温度对应的仍然是 (3/2)kT

一、选择题 每题 5 分，共 20 分

1.两种不同种类的理想气体，温度相同，则它们的分子平均平动动能：
A一定相同
B质量大的更大
C质量小的更大
D无法比较
2.一定量理想气体向真空绝热自由膨胀（膨胀后不对外做功），膨胀后温度：
A升高
B降低
C不变
D先降后升
3.在 p-V 图上，一个正循环（顺时针）所包围的面积表示：
A循环中吸收的总热量
B循环中内能的变化
C工质对外所做的净功
D循环效率
4.关于熵增原理，正确的是：
A一切过程都满足 ΔS ≥ 0
B孤立系统中 ΔS ≥ 0，等号对应可逆过程
C孤立系统中 ΔS ≤ 0
D可逆过程 ΔS 一定大于零
展开选择题答案
1. A　ε̄k = (3/2)kT，只与温度有关，与气体种类、质量无关。
2. C　Q = 0（绝热）、W = 0（向真空，无阻力）→ ΔU = 0 → 理想气体内能只与 T 有关 → T 不变。注意：这是「绝热自由膨胀」，不是「绝热膨胀」，别把 Q=0 就直接套 TVγ−1 = 常数，那个式子要求可逆。
3. C　净功 W = ∮p dV。顺时针为正（对外做功），逆时针为负。
4. B　熵增原理只对孤立系统成立。非孤立系统放热时熵会减小（如卷一第 3 题的 B 选项）。

二、填空题 每空 3 分，共 18 分

5.1 mol 刚性双原子理想气体在等容过程中温度升高 100 K，则 W = ?，Q = ?。
6.一卡诺制冷机工作在 300 K（高温热源）与 250 K（低温热源）之间，其制冷系数 w = ?。
7.熵的微观（统计）意义由玻尔兹曼关系给出：S = ?，其中 Ω 为宏观态对应的微观状态数。
展开填空题答案
5.　W = 0（等容，ΔV = 0）；
Q = ΔU = (5/2)νRΔT = 2.5 × 8.31 × 100 = 2.08×10³ J（吸热） 6.　w = T₂/(T₁−T₂) = 250/(300−250) = 5。
易错：制冷系数分母是「温差」，不是 T₁；而且 w 可以大于 1，这跟热机效率 η < 1 不矛盾 7.　S = k ln Ω（k 为玻尔兹曼常数）。Ω 越大 → S 越大，这就是「熵是混乱度的量度」的数学表达。

三、计算与简答题 共 62 分

8.（12 分）1 mol 单原子理想气体，初温 300 K，经绝热膨胀体积变为原来的 8 倍。求末温、气体做的功和内能变化。
9.（12 分）某卡诺热机工作在 500 K 与 300 K 两个热源之间，每次循环从高温热源吸热 1000 J。求： (1) 热机效率；(2) 每次循环做的功；(3) 向低温热源放出的热量。
10.（12 分）1 mol 理想气体向真空自由膨胀，体积变为原来的 2 倍。求熵变。并说明为什么不能直接用 ΔS = Q/T 计算。
11.（12 分）把 1 kg、100 ℃ 的水与 2 kg、20 ℃ 的水混合（绝热容器，c = 4.18×10³ J/(kg·K)）。求： (1) 平衡温度；(2) 混合过程的总熵变。
12.（14 分）分别叙述热力学第二定律的开尔文表述和克劳修斯表述，并说明两者等价。
展开计算题答案与解析
8. 单原子 γ = 5/3，绝热过程 TVγ−1 = 常数，γ−1 = 2/3
T₂ = T₁(V₁/V₂)2/3 = 300 × (1/8)2/3 = 300 × 1/4 = 75 K ΔU = (3/2)νR(T₂−T₁) = 1.5 × 8.31 × (75−300) = −2.80×10³ J 绝热 Q = 0，所以 W = −ΔU = 2.80×10³ J（气体对外做功） 易错：绝热过程 Q=0，但 ΔU 和 W 都不为零，它们大小相等符号相反
展开计算题答案与解析
9.
(1) η = 1 − T₂/T₁ = 1 − 300/500 = 40% (2) W = ηQ₁ = 0.4 × 1000 = 400 J (3) Q₂ = Q₁ − W = 1000 − 400 = 600 J 卡诺效率只由两个热源温度决定，与工作物质无关
展开计算题答案与解析
10. 自由膨胀是不可逆过程，且温度不变（理想气体向真空膨胀不做功、不吸热）。
熵是状态函数，初末态与「等温可逆膨胀」相同，所以可以借用那条可逆路径：
ΔS = νR ln(V₂/V₁) = 1 × 8.31 × ln2 ΔS ≈ 5.76 J/K 为什么不能用 ΔS = Q/T：那个式子的前提是可逆。自由膨胀 Q = 0，若直接套会得出 ΔS = 0，与熵增原理矛盾。这就是为什么必须「设计可逆路径」。
展开计算题答案与解析
11.
(1) 热平衡：1×(100−T) = 2×(T−20) → 3T = 140 → T ≈ 46.7 ℃ = 319.8 K (2) 热水降温：ΔS₁ = 4180 × ln(319.8/373) = −643 J/K 冷水升温：ΔS₂ = 2×4180 × ln(319.8/293) = 731 J/K 总熵变 ΔS = −643 + 731 ≈ +88 J/K > 0，符合熵增原理 易错：两段必须分开算再相加，不能先求平均温度再套公式
展开简答题答案与解析
12.
开尔文表述：不可能从单一热源吸收热量，使之完全变为有用功而不产生其他影响。（即第二类永动机不可能制成）
克劳修斯表述：热量不可能自发地从低温物体传到高温物体。
等价性：若开尔文表述不成立（能从单一热源吸热全变功），就可以用它驱动制冷机，把热量从低温搬到高温而不留痕迹，克劳修斯表述也不成立；反之亦然。两者说的是同一件事的两个侧面。
