T1 · 气体动理论

状态方程与压强

理想气体状态方程
pV = νRT = (m/M)RT = NkT
ν 摩尔数，R = 8.31 J/(mol·K)，k = 1.38×10⁻²³ J/K，N 分子数
压强（微观本质）
p = (1/3) n m v̄² = (2/3) n ε̄k
n = N/V 数密度，ε̄k = (1/2)m v̄² 平均平动动能
温度的微观意义
ε̄k = (3/2) kT
温度是分子平均平动动能的量度——只与平动有关，与转动无关

能量均分定理

每个自由度的平均动能
(1/2) kT
单原子 i=3（只有平动）；刚性双原子 i=5（3 平动 + 2 转动）；刚性多原子 i=6
理想气体内能
U = (i/2) νRT
只与温度有关，与体积、压强无关——这条是解题关键

三种速率（必背）

速率公式用途
最概然速率 vp√(2RT/M)速率分布曲线的峰值位置
平均速率 v̄√(8RT/πM)算平均自由程、碰撞频率
方均根速率 √(v̄²)√(3RT/M)算平均平动动能
三者比例
vp : v̄ : √(v̄²) = 1 : 1.128 : 1.225
记住「最概然 < 平均 < 方均根」就不会搞混
平均自由程
λ = kT / (√2 π d² p)
d 分子有效直径。与压强成反比、与温度成正比

T2 · 热力学第一定律

核心公式（符号规定：吸热为正，系统对外做功为正）
Q = ΔU + W　　dQ = dU + p dV
符号错一次，整题全错。先把符号规定写在卷子边上

四种过程对比（最高频考点）

过程WΔUQ特征式
等容0(i/2)νRΔT= ΔUV = 常数
等压pΔV = νRΔT(i/2)νRΔT(i/2+1)νRΔTp = 常数
等温νRT ln(V₂/V₁)0= WpV = 常数
绝热−ΔU(i/2)νRΔT0pVγ = 常数
四个最容易错的地方 ① 等温 ΔU = 0 但 Q ≠ 0（热量全变成功）
② 绝热 Q = 0 但 ΔU ≠ 0（靠消耗内能做功）
③ 等压摩尔热容 Cp = CV + R，多出来的 R 就是「维持压强不变要额外做的功」
④ 绝热过程方程里的 γ = Cp/CV = (i+2)/i，单原子 1.67、双原子 1.40
摩尔热容
CV = (i/2)R　　Cp = ((i+2)/2)R　　γ = Cp/CV
单原子 i=3：CV=1.5R，Cp=2.5R，γ=5/3

循环过程

一个循环结束后
ΔU = 0　→　Q净 = W净
循环的关键：内能回到原点，所以「吸收的总热量 = 对外做的总功」
热机效率
η = W净 / Q吸 = 1 − |Q放| / Q吸
分母只算「吸」的热量，不含放出的——这里错了扣分最多

T3 · 热力学第二定律

卡诺循环效率（效率上限）
η卡 = 1 − T₂/T₁
T₁ 高温热源、T₂ 低温热源，必须用热力学温度 K。任何工作在同一对热源之间的热机，效率都不可能超过它
熵的定义
dS = dQ可逆 / T　　ΔS = ∫ dQ可逆/T
熵是状态函数——只与初末态有关。但计算时必须设计一条可逆路径来积分
熵增原理
孤立系统：ΔS ≥ 0（可逆取等号）
这是第二定律的数学表达：孤立系统的自发过程总是朝熵增方向

熵变计算四类（考试就这四种）

类型怎么算
理想气体过程ΔS = νCVln(T₂/T₁) + νR ln(V₂/V₁)
可逆相变ΔS = Q/T = m·L/T（L 为相变潜热，T 为相变温度）
混合（不同温度）分两段算：ΔS = m₁c·ln(T/T₁) + m₂c·ln(T/T₂)
不可逆过程设计可逆路径：先等温再等容，或先等压再等温，用状态函数性质绕过去
第四类是重点也是难点 熵是状态函数，所以「不可逆过程的熵变 = 同样初末态之间任意可逆路径的熵变」。碰到自由膨胀、热传导这类不可逆过程，千万不要直接拿 dQ/T 算（因为过程不可逆，那个积分不成立），要自己造一条可逆路径。
第二定律的两种表述（可能考简答） 开尔文表述：不可能从单一热源吸热，使之完全变成功而不产生其他影响（第二类永动机不可能）
克劳修斯表述：热量不可能自发地从低温物体传到高温物体

三类必考题

① 求某过程的 Q / W / ΔU 步骤固定：先在 p–V 图上标出初末态 → 判断是什么过程 → 套对应公式。热学题的难点不在计算量，在符号和方向。
② 循环效率 步骤：拆成几个分过程 → 逐个算 Q（注意正负）→ 把所有 Q>0 的加起来当分母 → W净 当分子。最容易错的是把放热也加进分母。
③ 熵变 先判断是不是可逆。可逆直接积分；不可逆先设计路径。混合、相变、自由膨胀各有一套。
